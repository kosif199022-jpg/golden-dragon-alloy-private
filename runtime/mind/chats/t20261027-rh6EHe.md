# إضافة After Effects MCP للبروتوكول

<!-- t20261027-rh6EHe · بدأت 2026-10-27 06:35 · آخر تحديث 2026-10-27T17:55 · المصدر: محادثة مشروع cmsg_01YEQ6nZK9FutfMTHk8GjtPNMKsyfzra4MKc1tJurh6EHe -->

**الموضوع:** إضافة جسور MCP لبرامج أدوبي (أفتر إفكتس، بريمير، فوتوشوب) للبروتوكول USIP v5.8، وبعدها برامج مونتاج تانية.

- **الطلبات:** ضيف after-effects-mcp للبروتوكول بخطوات تسطيب، ودوّر على ربط بريمير (وفوتوشوب من المنسّق) → قارن adb-mcp بالبدائل → «ادمجهم كلهم عندي وبعدين قولي أستخدمهم إزاي» → «في برامج تانية من عمالقة المونتاج؟».
- **النتيجة:** PR #157 اتدمج. أدوات محلية اختيارية (MIT، مجانية): after-effects-mcp (~804⭐)، premiere-pro-mcp (~247⭐، ~369 أداة؛ `npm install -g premiere-pro-mcp` ثم `premiere-pro-mcp --install-cep`)، photoshop-mcp (~318⭐، 102 أداة، سطر npx واحد)، وadb-mcp احتياطي (تجريبي، 5 برامج، محتاج سيرفر Python + بروكسي Node). سكربت `adobe_mcp.py` يطلع خطوات التسطيب ويفحص الناقص. دليل استخدام Artifact. اقتراح 4 برامج تانية: davinci-resolve-mcp (~2.2k⭐، `npx davinci-resolve-mcp setup`)، VectCutAPI لـ CapCut (~2.3k⭐)، blender-mcp (~32.5k⭐)، fcp-mcp (88 أداة، ماك، بيتا).
- **ملفات ومسارات:** https://github.com/kosif199022-jpg/kosif-tool/pull/157 · دليل: https://claude.ai/artifact/JPbZNjL32hPTPei15yDNcF · https://github.com/Dakkshin/after-effects-mcp · https://github.com/leancoderkavy/premiere-pro-mcp · https://github.com/alisaitteke/photoshop-mcp · https://github.com/mikechambers/adb-mcp · https://github.com/samuelgursky/davinci-resolve-mcp · https://github.com/sun-guannan/VectCutAPI · https://github.com/ahujasid/blender-mcp · https://github.com/dreliq9/fcp-mcp
- **أرقام مقاسة:** فحوص 1330 اختبار + 323 ناجحين.
- **قرارات:** الترشيح: الجسور التلاتة المنفصلة أقوى من adb-mcp؛ ابدأ بفوتوشوب (الأسهل). بعدها DaVinci أقرب بديل لبريمير وأقوى في الألوان، وCapCut للريلز. adobe-mcp-rs (~31⭐) مش أحسن. مفيش MCP رسمي من أدوبي لبرامج الديسكتوب.
- **دروس وأخطاء:** الجسور ماتجرّبتش على برامج أدوبي فعلًا (البيئة مفيهاش أدوبي) والمعلومات من صفحات المشاريع. التسطيب لازم على جهازه مع Claude Desktop أو Claude Code؛ الويب والموبايل مش بيوصلوا لبرامج الجهاز.
- **حدود ورفض:** مفيش.
- **مفتوح:** سؤال «تحب أضيف الأربعة (DaVinci، CapCut، Blender، FCP) للبروتوكول؟» من غير رد هنا (اتعمل في محادثة «تسليم المونتاج لدافنشي وبريمير وبلندر»).
