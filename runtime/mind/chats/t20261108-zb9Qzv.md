**الموضوع:** قايمة بأهم مستودعات GitHub اللي تساعد في المونتاج، مترتبة حسب فايدتها للتنين الأسود.

- **الطلبات:** «ابحث عن اهم مستودعات ممكن انزلها تساعد في المونتاتج».
- **النتيجة:** قايمة ١٧ مستودع بالنجوم والرخصة (اتراجعوا من GitHub يومها):
  - أولوية: browser-use/video-use (30.7k، MIT، أقرب حاجة لفكرة التنين: خد SKILL.md وhelpers)، heygen-com/hyperframes (80.7k، Apache-2.0، HTML→فيديو والعربي بيترسم صح)، m-bain/whisperX (25k، BSD-2، توقيت كلمة بكلمة)، WyattBlue/auto-editor (5.8k، Unlicense، قص السكتات + تصدير بريمير/دافينشي)، facebookresearch/demucs (10.4k، MIT، فصل صوت/مزيكا).
  - صوت وإيقاع: Rikorose/DeepFilterNet، librosa/librosa.
  - موشن: remotion-dev/remotion (71.5k، مجانية للأفراد والشركات ٣ أشخاص أو أقل بس)، Zulko/moviepy، ManimCommunity/manim.
  - قص عمودي وتأثيرات: google-ai-edge/mediapipe، facebookresearch/sam2، hzwer/ECCV2022-RIFE، danielgatis/rembg.
  - أفكار: harry0703/MoneyPrinterTurbo (140k)، veedstudio/open-edit (أجزاء محتاجة حساب VEED)، mifi/lossless-cut (GPL-2.0).
