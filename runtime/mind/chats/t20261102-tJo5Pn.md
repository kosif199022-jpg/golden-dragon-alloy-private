# دمج قدرات VoiceStudio في المهارة

**الموضوع:** «https://github.com/debpalash/VoiceStudio ادمج قدراته في المهارة».
- **الطلبات:** دمج قدرات مستودع VoiceStudio في kosif-tool؛ وبعدين «ادمج» (اتكتبت في ثريد goclone والمنسق وصّلها).
- **النتيجة:** مهارة جديدة `kosif-voice-studio` + أداة `voice_studio.py` اتدمجت في main (PR #209). بتعمل: تعليق صوتي مصري مجاني بـ edge-tts (صوت سلمى أو شاكر) + ملف توقيت لكل كلمة للمونتاج (كليب 5 ث اتعمل فعلًا)؛ صوت عربي أوفلاين بـ piper؛ تفريغ لـ SRT بـ Whisper؛ استنساخ صوت وتصميم صوت من وصف عن طريق API بتاع VoiceStudio لما يكون شغال على جهازه (اتجرّب على نسخة تجريبية بس). في السكة اتصلح خطأين كانوا موقّعين CI بتاع main نفسه: أداة «التنين ميديا» مش متسجلة، وفحص التنين مستني رقم خروج قديم.
- **ملفات ومسارات:** https://github.com/kosif199022-jpg/kosif-tool/pull/209 · `voice_studio.py` · مهارة `kosif-voice-studio`.
- **أرقام مقاسة:** 13 تيست للأداة؛ 533 تيست في المستودع ناجحين.
- **قرارات:** VoiceStudio رخصته AGPL-3.0 → مافيش نسخ كود، الكلام معاه من برّه بالـ API عشان المستودع يفضل حر. الموديل الافتراضي بتاعه مش مسموح تجاريًا.
- **دروس وأخطاء:** فحص GitHub وقع بسبب أداة في main مش متسجلة (مش من الـ PR) → سجّلها وأعاد توليد الملفات المولّدة. بعد ما main يتحدّث (مهارة خيال الظل نزلت) لازم دمج main وإعادة توليد الفهارس وتشغيل خطوات CI محليًا.
- **حدود ورفض:** رخصة AGPL وموديل غير تجاري.
- **مفتوح:** تجربة الاستنساخ على VoiceStudio الحقيقي على جهازه.
