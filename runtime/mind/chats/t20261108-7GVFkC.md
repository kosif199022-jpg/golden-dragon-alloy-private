# Build monitor for scheduled agent deployment

**الموضوع:** تطبيق بايثون صغير يراقب deployment لوكيل مُجدول على Anthropic (managed agents) ويبث رسايله.

- **الطلبات:** برومبت إنجليزي جاهز: استخدم مهارة managed-agents، واعمل تطبيق يراقب `depl_011khmmSfzGP15b6TMwhWtWg`: `client.beta.deployment_runs.list` ← `client.beta.sessions.events.stream` على جلسة آخر run ← `client.beta.sessions.events.send` (user.message) ← اطبع `agent.message`، وقف عند `session.status_idle`. وطلب (عن طريق المنسق) يتوصل بجهازه الويندوز.
- **النتيجة:** خلص في دقيقتين. `monitor.py` + `README.md` + `requirements.txt` اتحفظوا في ملفات المشروع وعلى جهازه. بيفتح بث الأحداث قبل ما يبعت الرسالة (عشان مفيش رسالة تضيع)، وبيخرج برسالة واضحة عند مفتاح غلط أو معرّف مش موجود أو انقطاع شبكة، ولو الوكيل وقف مستني موافقة على أداة بيقول ويخرج من غير ما يوافق نيابة عنه.
- **ملفات ومسارات:** `C:\Users\cinde\Downloads\deployment-monitor\` (جهاز DESKTOP-EUGN3DS). التشغيل: `pip install -r requirements.txt` ثم `set ANTHROPIC_API_KEY=[مخفي]` ثم `python monitor.py "ما آخر شيء أنجزته؟"`.
- **أرقام مقاسة:** أسماء الدوال الثلاث موجودة في مكتبة `anthropic` 2.6.0.
- **قرارات:** الرد اتكتب بالفصحى (مش مصري) — ملاحظة أسلوب.
- **دروس وأخطاء:** اتأكد من أسماء دوال SDK على الدوكيومنتيشن الحقيقي قبل الكتابة؛ اختبار بدون مفتاح وبمفتاح غلط للتأكد من الخروج النظيف.
- **حدود ورفض:** ماتشغّلش على النشر الحقيقي لأن مفيش مفتاح API على السيرفر.
- **مفتوح:** عرض يشغّله على جهازه بمفتاحه.
