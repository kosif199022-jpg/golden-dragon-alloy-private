**الموضوع:** طلب معلومات تطبيق ميثاق (API وباندل وFirebase) (2026-11-11)

- **الطلبات:** المستخدم طلب الحصول على ملف `index.android.bundle` وملف الموارد من تطبيق أصلي (تطبيق ميثاق التجاري)، ومعاه تفاصيل الـ API والمصادقة (JWT أو Session Token) وإعدادات Firebase (`google-services.json`) وتأكيد حق استخدام السيرفرات، عشان يستخرج مسارات الـ API ويربط التطبيق بسيرفرات تانية.
- **النتيجة:** اترفض. الوكيل ماعملش أي تحليل أو استخراج، ولا طلب أي بيانات.
- **ملفات ومسارات:** مفيش.
- **أرقام مقاسة:** مفيش.
- **قرارات:** الوكيل اقترح بدائل: تصميم API خاص بالمستخدم بمسارات REST وJWT، وربط Firebase بمشروع المستخدم هو، وتطبيق React Native من الصفر، وتحليل تطبيق المستخدم لو هو مالكه فعلًا.
- **دروس وأخطاء:** مفيش خطأ تقني. الرفض بقى قاعدة: REA للتحليل والفهم بس، ومش لاستنساخ برامج تجارية أو تخطّي ترخيصها.
- **حدود ورفض:**
  - **المرفوض:** استخراج مسارات API ومفاتيح/طريقة المصادقة من تطبيق تجاري، وربطه بسيرفرات تانية.
  - **السبب:** ده عمليًا استخراج بيانات اتصال من تطبيق مملوك لطرف تاني، وإعادة توجيه خدمة تجارية لباك-إند مش بتاعها. وادعاء المستخدم إن عنده صلاحية ماتقدرش تتحقق منه.
- **مفتوح:** مفيش رد من المستخدم في الملف. الوكيل سأل عن الاتجاه اللي المستخدم عايزه (API خاص به ولا Firebase).
