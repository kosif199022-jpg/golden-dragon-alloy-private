# Publish 4K videos directly to TikTok

<!-- t20261025-ysVJzd · بدأت 2026-10-25 15:08 · آخر تحديث 2026-10-25T15:21 · المصدر: محادثة مشروع cmsg_01YEQ6nZK9FutfMTHk8GjtPNHJhgvbdBBKpt9f6TysVJzd -->

**الموضوع:** نشر فيديو 4K مباشر على تيك توك من Claude Code على الموبايل عبر Higgsfield، + عيب `--scale 2` في أداة الرندر.

- **الطلبات:** تقرير مشكلة مفصّل (مكتوب من جلسة تانية) + «عايز نشر مباشر على التيك توك عشان نحافظ على الجودة»، وبعدين «ادمج فورا».
- **النتيجة:**
  - تيك توك: النشر المباشر من جلسة Claude Code على الموبايل مش ممكن. `tiktok_publish` لازم من widget بتاع MCP Apps (خصوصية + موافقة)، وClaude Code موبايل مابيعرضوش، والأداة بتمنع الوكيل يستدعيها أو يبني فورم بديل. `UPLOAD_TO_DRAFT` برضه بيعدّي على نفس الفورم، ومفيش deep link ويب. الحل: يكمّل من claude.ai أو تطبيق Claude العادي (الفيديو مرفوع جاهز على Higgsfield، وتيك توك بيسحب الأصل).
  - الرندر: PR #147 اتدمج — `--scale 2` في وضع seek بيطلع 2160×3840 فعلًا؛ وضع virtual مايقدرش يكبّر، فبيقف من الأول برسالة تقول استخدم `--width 2160 --height 3840`.
- **ملفات ومسارات:** `tools/render_html.cjs`، PR: https://github.com/kosif199022-jpg/kosif-tool/pull/147
- **أرقام مقاسة:** الفيديو 2160×3840، 30fps، 66 ث، 121 MB، H.264/AAC. الرصيد على Higgsfield ماتأثرش (1208.03 قبل وبعد). connector_id [مخفي].
- **قرارات:** TikTok Content Posting API الرسمي محتاج تطبيق مطوّرين ومراجعة، والنشر قبل الموافقة SELF_ONLY → مش منصوح بيه دلوقتي. دمج قبل ما فحص check يخلص بطلب «فورا» (اختبارات الرندر كانت عدّت محليًا).
- **دروس وأخطاء:**
  - `render_html.cjs --scale 2` كان بيطلع 1080×1920 ويفشل بـ `screenshot is 1080x1920, expected 2160x3840` (seek مع canvas) → اتصلح؛ البديل `--width 2160 --height 3840` والصفحة تكبّر الـ canvas حسب `window.innerWidth`.
  - widgets بتاعة MCP Apps مش بتظهر في Claude Code موبايل → أي خطوة محتاجة فورم موافقة تتعمل من claude.ai/تطبيق Claude.
  - تيك توك بيعيد ضغط أي فيديو بعد الرفع على أي حال.
- **حدود ورفض:** الوكيل مايستدعيش `tiktok_publish` بنفسه ومايبنيش فورم موافقة بديل (بالتصميم).
- **مفتوح:** النشر نفسه متروك لصاحب الشغل من claude.ai.
