**الموضوع:** نقل الـ114 مهارة من مستودع `100-superskills` لجوه سوبر باور (kosif-tool).

- **الطلبات:** «انقل قدرات مستودع 114 مهارة الى سوبر باور» → بعدين «ادمج» و«ادمج كل حاجة في main فورًا».
- **النتيجة:** اتدمج في main. الـ114 مهارة اتنسخوا كاملين (682 ملف ببصمة SHA-256)، أداة `scripts/superskills.py` (بحث بالعربي، عرض، تثبيت، فحص، تشغيل اختبارات)، وربطها بـ `scripts/hub.py find`.
- **ملفات ومسارات:** https://github.com/kosif199022-jpg/100-superskills · https://github.com/kosif199022-jpg/kosif-tool/pull/155 · الاستخدام: `python3 scripts/hub.py find "طلبك"` أو `python3 scripts/superskills.py find "طلبك"`.
- **أرقام مقاسة:** قبل: 72 مهارة متسجلة كمراجع بس و42 مش موجودة. 215 اختبار للمهارات نفسها نجحوا بعد 5 إصلاحات (kosif-one، pixel-studio، kosif-social، kosif-montage-motion). اختبارات المستودع 1311 (قبلها 1367) نجحت، واختبار جديد 12/12.
- **قرارات:** المهارات تتنسخ ملفات حقيقية مش submodule. تعديلات المجلس (A38) في PROTOCOL.md اتسابت لـ PR #152. #155 اتدمج بعد #152 مع إعادة بناء الفهارس.
- **دروس وأخطاء:**
  - PR #153 ربط المستودع كـ submodule → جلسات Claude على الكلاود بتنزّل المستودع من غير submodules فالمهارات ماكانتش بتوصل → انسخ الملفات نفسها.
  - main وقع في فحص حجم البروتوكول بعد دمج #154 → اتصلّح جوه #155.
  - CI بيمنع ملفات wav جوه المهارة → أصوات الكيبورد اتحولت FLAC من غير فقد، وفهرس المكتبة اتعاد.
  - PRs متوازية بتعدّل نفس ملفات الفهرس (#152 و#155) → اللي يندمج تاني يعيد بناء الفهارس فوق main الجديد.
