# Suno MCP HTTP transport

<!-- s20261104-AhqRSV · بدأت 2026-11-04 15:43 · آخر تحديث 2026-11-04T15:44 · المصدر: جلسة سحابة session_01BWUMonTCYzaAkrXMAhqRSV -->

**الموضوع:** إضافة Suno كسيرفر MCP (`claude mcp add --transport http suno https://api.suno.com/mcp`).

- **الطلبات:** نفّذ أمر الإضافة؛ بعدها «ضفته من Connectors اتأكد إنه متصل»؛ وبعدها «ابعتلي mcp انسخه».
- **النتيجة:** الأمر اتنفذ في الحاوية (اتكتب في `/root/.claude.json` بس)، والسيرفر رد 401 (محتاج تسجيل دخول). ListConnectors ماطلعش فيه Suno: الموجود Higgsfield وgraphify متصلين، وRemote Desktop Commander محتاج Reconnect. اتبعتله العنوان والأمر وشكل `.mcp.json` جاهزين للنسخ.
- **ملفات ومسارات:** فرع `claude/suno-mcp-http-transport-rm1ejv` في `kosif199022-jpg/kosif-tool`؛ المرجع `.claude/skills/kosif-superpowers/references/protocol/A46-suno-mcp.md`.
- **أرقام مقاسة:** `curl https://api.suno.com/mcp` → 401.
- **قرارات:** مفيش توكن اتكتب في ملف ولا تغيير في الريبو.
- **دروس وأخطاء:**
  - `claude mcp add` جوه جلسة سحابية بيتسجل محليًا في الحاوية ويتمسح، والأدوات بتتحمل أول الجلسة بس → الطريق الصح: claude.ai ← Settings ← Connectors ← Add custom connector (Suno، `https://api.suno.com/mcp`) ← Connect، وبعدين جلسة جديدة.
  - Connector اتضاف وسط الجلسة مش بيظهر فيها → افتح جلسة جديدة وقول «اتأكد من Suno» (اختبار بأداة قراءة بس، من غير كريدت).
- **حدود ورفض:** مفيش.
- **مفتوح:** التأكد إن Suno اتعمله Connect فعلًا في حسابه.
