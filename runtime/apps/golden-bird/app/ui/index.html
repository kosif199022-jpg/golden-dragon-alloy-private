طريقة التشغيل

«اشتراك Claude» بيشغّل برنامج Claude Code الأصلي المتثبت عندك وهو داخل باشتراكك (Pro/Max)، والاستخدام بيتحسب من حدود الاشتراك مش من الرصيد. «رصيد API» بيستخدم مفتاح API والدفع بالتوكن.

إضافة كروم 🧩

الإضافة بتخلّي الطائر يفتح الصفحات في كروم بتاعك ويقراها ويضغط ويكتب فيها، لما تفعّل «🖥 تحكم في الجهاز وكروم» في المحادثة.
التثبيت مرة واحدة:
1) دوس «افتح مجلد الإضافة» تحت.
2) في كروم افتح chrome://extensions وفعّل Developer mode من فوق على اليمين.
3) دوس Load unpacked واختار المجلد اللي اتفتح.
4) دوس على أيقونة الإضافة 🦅 في كروم، والزق كود الربط، ودوس «حفظ وربط».

GitHub 🐙

اشتراكات تانية
بيشتغلوا عن طريق الأدوات الرسمية لكل منصة وهي داخلة بحسابك: Codex CLI لاشتراك ChatGPT، وGemini CLI لحساب جوجل. التطبيق مش بيشوف بيانات دخولك؛ الدخول بيتم في نافذة المنصة نفسها.
🔷 Gemini بمفتاح Google AI Studio (بديل Antigravity المسموح)
جوجل بتمنع ربط حساب Antigravity بأي برنامج تاني، وده ممكن يوقّف حسابك. وبتنصح بمفتاح من Google AI Studio (aistudio.google.com ← Get API key) عشان تستخدم نفس موديلات Gemini. المفتاح بيتحفظ في خزنة ويندوز.

مفتاح Anthropic API

بيتحفظ في خزنة ويندوز (Credential Manager)، مش في ملف. ماتشاركهوش في أي شات.
