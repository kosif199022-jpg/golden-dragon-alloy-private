# Cinema C V31.0 — Smart Media (iPhone / a-Shell)

تطوير موحّد مبني على Cinema C V30.1 مع الحفاظ على خيارات الفيديو والصوت والجودة وحفظ الملفات وفحص صفحات فيسبوك المتاح علنًا.

## ما الذي تغيّر؟

- تحميل منشورات إنستجرام التي تحتوي على صور، أو صور متعددة (carousel)، أو صور وفيديوهات معًا باستخدام `gallery-dl`.
- عند فشل `yt-dlp` لأن المنشور لا يحتوي على فيديو، يحاول البرنامج التحويل إلى `gallery-dl` تلقائيًا **لروابط منشورات إنستجرام `/p/`**.
- وضع SMART (رقم 11): أولوية لتنزيل **كل ملفات** المنشور بدل الاعتماد على فيديو واحد فقط.
- وضع GALLERY (رقم 12): استخدام `gallery-dl` للمنشورات المدعومة.
- `--setup`: تثبيت أو ترقية الحزم بطلب صريح من المستخدم (لا تحديث قسري عند الفشل).
- `--doctor`: فحص حالة yt-dlp وgallery-dl وffmpeg وPython ومسار التحميل.
- مسارات cookies النسبية أصبحت مطلقة قبل فحص فيسبوك الذي يغيّر مجلد التشغيل.
- اختيار جودة 480p/720p/1080p وغيرها لا يتجاوز الحد المحدد بشكل صامت.
- تنزيل الألبومات في مجلد فرعي خاص لكل منشور منعًا لفقد ملفات أو الكتابة فوقها.
- الإبقاء على الفيديو الأصلي عند إنشاء نسخة MP4 متوافقة مع صور الآيفون.
- الحفاظ على آلية فحص ملفات التعريف في فيسبوك ذات المعرّف الرقمي مع التحقق من بوابة تسجيل الدخول؛ **هذا الفحص تقريبي ولا يضمن الوصول لكل الفيديوهات**.

## التثبيت على a-Shell في الآيفون

1. احفظ `Cinema_C_V31_SmartMedia_iPhone.sh` في مجلد `Documents` التابع لتطبيق a-Shell، أو انتقل في a-Shell إلى المجلد الذي حفظته فيه.
2. نفّذ:

```sh
sh ./Cinema_C_V31_SmartMedia_iPhone.sh --install
```

3. ثبّت الأدوات الناقصة (يتطلب اتصالًا بالإنترنت وPython/pip يعملان في a-Shell):

```sh
c --setup
```

4. افحص الجاهزية:

```sh
c --doctor
```

5. شغّل البرنامج المعتاد:

```sh
c
```

إذا لم يتعرف a-Shell على الأمر `c` بعد التثبيت، شغّله مباشرة:

```sh
sh "$HOME/Documents/bin/c" --doctor
```

أو أضف مسار أدوات Cinema إلى PATH في الجلسة الحالية:

```sh
export PATH="$HOME/Documents/bin:$PATH"
```

**ملاحظة:** على بعض إصدارات a-Shell قد تفشل عملية `pip install --user` بسبب قيود البيئة. في هذه الحالة افحص رسالة `c --doctor` واستخدم آلية تثبيت الحزم التي يدعمها إصدار a-Shell لديك؛ السكربت نفسه لا يضمن تنزيل الحزم أو توافقها مع جميع إصدارات iOS.

## أمثلة التشغيل

### منشور إنستجرام به صور/فيديو أو ألبوم كامل

```sh
c --files --smart "https://www.instagram.com/p/POST_ID/"
```

### تنزيل المنشور بواسطة gallery-dl مباشرة

```sh
c --files --gallery "https://www.instagram.com/p/POST_ID/"
```

### فيديو Reel / TikTok / YouTube أو غيرها من المواقع المدعومة

```sh
c --files "https://www.instagram.com/reel/REEL_ID/"
```

اختر رقم الجودة من القائمة؛ `1` للأفضل و`2..6` لحد أقصى للجودة و`7` لملف MP4 سريع و`8..9` للصوت و`10` لعرض صيغ الموقع و`11` للوضع الذكي و`12` لوسائط المعرض.

### طلب فتح مشاركة iOS للحفظ في تطبيق «الصور»

```sh
c --photos --smart "https://www.instagram.com/p/POST_ID/"
```

- الصورة المفردة: يحاول فتح الملف في واجهة المشاركة؛ اختر «حفظ الصورة» (Save Image).
- فيديو منفرد: يحاول إنشاء MP4 متوافق بصيغة H.264/AAC ثم فتحه؛ اختر «حفظ الفيديو» (Save Video).
- ألبوم متعدد العناصر: يحفظ الملفات في مجلد منفصل أولًا؛ افتحه في تطبيق «الملفات» وحدد العناصر للمشاركة والحفظ. **لا يقوم بالحفظ التلقائي المباشر في مكتبة صور iOS دون موافقة المستخدم**.

### Cookies للمحتوى المسموح لك بالوصول إليه

```sh
c --cookies cookies.txt --files --smart "https://www.instagram.com/p/POST_ID/"
```

يجب أن يكون الملف بصيغة Netscape/Mozilla. لا تشارك ملفات cookies مع الآخرين ولا تُحمّل محتوى خاصًا دون إذن. ليس هناك تجاوز إجباري لقيود التسجيل أو المحتوى المحمي.

### فيسبوك — صفحات profile.php ذات ID رقمي

```sh
c "https://www.facebook.com/profile.php?id=123456789"
```

يقوم بفحص أسطح عامة محدودة فقط، ويطلب تأكيد التنزيل. في حال ظهور بوابة تسجيل الدخول يوضح الحاجة إلى جلسة مصرح بها. لا يضمن حصر كل الفيديوهات من صفحة الملف الشخصي.

## أماكن الحفظ

- افتراضيًا: `$HOME/Documents/Cinema_Downloads`.
- المعرض/الألبومات: مجلد باسم `Instagram_POSTID_...` يحتوي الصور والفيديوهات.
- فيديو منفرد: الملف مباشرة في مجلد التنزيلات.
- محتوى فيسبوك دفعة واحدة: مجلد `Facebook_Profile_ID`.
- لتغيير المكان: `c --output /path/to/folder --files URL`.

## حدود التشغيل

- يتوقف دعم الصور على توفر `gallery-dl` وقد يتأثر بقيود إنستجرام، وتغيّر الموقع، وخصوصية المنشور، ومعدل طلبات الشبكة. التحديث وحده لا يصلح صورة منشورة لا تحتوي على فيديو في yt-dlp.
- استخراج كل فيديوهات ملف فيسبوك الشخصي ليس مضمونًا ولا يعد واجهة API رسمية.
- الاختبارات المرفقة **اختبارات محلية بمحاكاة أدوات التحميل**؛ لا تعني التحقق الفعلي من إنستجرام/فيسبوك أو من هاتف آيفون حقيقي.
- استخدم الأدوات فقط لتنزيل المحتوى الذي تملك الحق في حفظه، والتزم بشروط المنصات.

```sh
python3 tests/test_cinema.py
```

هذا الاختبار لا يصل إلى الإنترنت؛ ينشئ أدوات محاكاة لفحص السيناريوهات.
