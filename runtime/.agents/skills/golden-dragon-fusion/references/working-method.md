# Combined working method

Apply the relevant checks together to produce one final deliverable. Use the output of each step as the next step's input.

- Carry a shared visual reference through every shot or component. Check the delivered result against it.
- Map the requested sequence to shots or states before production. Preserve their timing when composing the final output.
- Derive captions from the actual speech, preserve language and direction, then inspect timing and readability in the export.
- Set dimensions and timing from the requested delivery format and measure both in the exported media.
- Carry field names, units and identifiers through transformations. Reconcile counts and totals against the input.
- Identify the input and record its provenance before interpreting or converting it.
- Turn the user's success condition into a check and exercise the actual entry point with representative input.
- Inspect the output in its intended language, reading direction and display size.
- Open the delivered artifact and check its contents and format. Report any unverified property.
