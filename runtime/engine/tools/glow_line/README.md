# خط مضيء على أسود (ST13) — v1990.7.0

من ريل _dreamscapes_sajna (13 ث، من غير كلام)، بطلب صاحب التنين: «قلده».

## القواعد
- خلفية سودا تمامًا (ده تصميم الريل، مش «بداية غامقة»)، **رسم خطي أبيض سكتش** (نفس المسار بيترسم 4 مرات بإزاحة بسيطة).
- **استعارة واحدة بتتحول:** راس بروفايل ← جواها كعبلة أفكار (منحنيات مقفولة عشوائية ثابتة) ← عامل صغير بكاب بيفكها ← الخيوط بتترتب (رصّة أفقية + أشعة) ← بتتحول دهبي وتنزل ستارة لقاعدة واحدة ← **شجرة دهبية بتنمو** (تفرّع recursive محدود بدايرة الجمجمة) ← العامل بينوّر عند الجذع.
- الدهبي بتلات ضربات: هالة عريضة شفافة + خط برتقالي + قلب فاتح. التوهج جزء من الرسم نفسه.
- من غير نص على الشاشة غير التوقيع في آخر 3 ث. الصوت الأصلي بالبايت.

## الاستخدام
`HEAD` نقط البروفايل، `ST` الخيوط (tangle/order/curtain)، `TREE` الشجرة، `man()` العامل. غيّر التوقيتات في `seg(t, …)` و`DUR`، ثم `bash tools/lyric_couple/render.sh JOB OUT.mp4`.
`dragon.py verify` هيحذّر من السواد: طبيعي في الستايل ده، قول لصاحب التنين.
