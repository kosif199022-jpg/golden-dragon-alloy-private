# فيلم حكاية أبيض وأسود (ST08) — v1990.5.0

ستايل اتنقل من ريل أغنية «كائن تلاتيني» (نور الدين محمد) بطلب صاحب التنين: «قلد الفديو تماما وطور التنين الأسود ليستطيع القيام بنفس الاستايل».

## الشكل
- كرتون **حبر أبيض وأسود** (ink cartoon)، شخصية واحدة ماشية في حكاية: زحمة وسبوت لايت، شارع مبلول لوحده، باب بيتقفل على الزحمة، مراية فيها نسخه الأصغر، جواه (قفص صدري وقلب)، وفي الآخر فوق سطح على المدينة.
- **لقطة متحركة لكل سطر** (Seedance Mini 480p 4 ث = 2 كريدت)، قطع حاد على أول السطر.
- **ترجمة صغيرة بيضا تحت** (Almarai 46، حد أسود رفيع)، والسطر التاني بيظهر fade على كلمته.
- **كارت النهاية أبيض**: اسم الأغنية بخط تقيل (Lalezar) واسم المطرب، وحواليه شخبطة يد (نجوم، نوتات، أسهم، لولب) بتترسم وبتـ«تغلي» 10 مرات في الثانية. التوقيع في آخر 3 ث على الكارت.
- **الشخصية:** مانقلش شخصية صاحب الريل (الستيك مان بتاعه)؛ بنستخدم الراجل بتاعنا C01 مرسوم حبر أبيض وأسود.

## التشغيل (ffmpeg بس، مفيش متصفح، خفيف على الديسك)
```bash
python scripts/dragon.py tool mono JOB JOB/spec.json --out film.mp4
python scripts/dragon.py tool mono --demo /tmp/x      # تجربة من غير نت
```
`spec.json`: `dur`، `audio` (بيتنسخ بالبايت)، `shots` (فيديو بيتبطّأ بـ minterpolate أو بيتقص، أو صورة بـ push-in)، `subs` `[بداية، نهاية، سطر1، سطر2، وقت سطر2]`، `card` `{start,title,by}`.
اللقطات لازم تغطي من 0 لحد بداية الكارت من غير فراغ (البرنامج بيرفض غير كده).

## Prompt اللقطة (gpt_image_2_6 مع مرجع الراجل)
`Black and white ink cartoon illustration, bold clean outlines, grey wash shading, dramatic light, 9:16. The man from the reference drawn in this cartoon style (round glasses, curly hair, plain black t-shirt, grey trousers, sneakers). Scene: ...`
وبعدين `generate_video` بـ seedance_2_0_mini 480p 4 ث بحركة بسيطة (يمشي، يلف، الكاميرا تقرب).
