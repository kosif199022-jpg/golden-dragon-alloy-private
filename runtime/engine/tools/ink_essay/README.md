# حبر على ورق (ST11) — v1990.7.0

من ريل ai.studio.1990 «الدائرة» (مش لازم تكون كامل حتى تترك أثر)، بطلب صاحب التنين: «قلده تمام مع وضع الصوت نفسه»، و«خلي الخط نفسه».

## القواعد
- ورق كريمي `#f2f0e7` بحبيبات خفيفة ثابتة، **خط حبر واحد** `#1d1d1b`، ورمادي `#8b8a84` للملصقات التقنية.
- **كل جملة من الراوي = حاجة بتترسم قدامك**: قلم بيرسم دايرة بإيد (متعرجة، مش مقفولة)، دايرة الحاسوب بنصف القطر و x²+y²=r²، مليون دايرة، أقواس التركيز، علامات الارتجاف، خطوط القياس r=…، الفجوة، حلقة دواير مختلفة، تمثال نصفي، اللولب البني، النسخة الرمادية، النقطة اللي بتنبض (الدافع).
- الكلام تحت (y≈1500) بخط **Almarai Bold** رمادي غامق، سطر أو سطرين — نفس خط الريل الأصلي بالظبط تقريبًا («خلي الخط نفسه»).
- الصوت الأصلي بالبايت. مفيش مؤثرات: الحركة كلها رسم.
- `human(seed)` = دايرة إنسان (توافقيات + انحراف + فجوة)، `perfect()` = دايرة الآلة، `pencil()` و`bust()` و`brackets()` و`lbl()`.
