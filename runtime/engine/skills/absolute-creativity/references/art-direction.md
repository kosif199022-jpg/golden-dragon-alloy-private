## 1. بناء العالم البصري

**المسار:** Concept → References → Rules → Style Bible → اختبار على 3 لقطات/أسطح مختلفة.

| المرحلة | السؤال | الناتج |
|---|---|---|
| Concept | الفكرة في جملة واحدة؟ الإحساس إيه؟ | سطر + 3 صفات (مثلا: «دافي، متروك، حنين») |
| References | إيه اللي شبه الإحساس ده؟ (مش الموضوع) | 12-20 صورة من 3 مصادر مختلفة على الأقل |
| Rules | إيه القواعد اللي تتكرر في كل لقطة؟ | palette, materials, shapes, textures, type, motion |
| Bible | صفحة واحدة تتبعت لأي حد | الجدول تحت |
| Test | القواعد تصمد قدام لقطة غريبة؟ | لو كسرت، عدّل القاعدة مش اللقطة |

قاعدة ذهبية: العالم يتعرّف بالقواعد والقيود، مش بالعناصر. القيود هي اللي بتخلّي الشغل «ليه صوت».

### Style Bible — قالب صفحة واحدة

| البند | الملء |
|---|---|
| الاسم + الجملة | «اسم العالم» — جملة الإحساس |
| Keywords (3) / Anti-keywords (3) | مثلا: دافي، خشن، صادق / لامع، ناعم زيادة، corporate |
| Palette | 5 HEX: dominant 60 / secondary 30 / accent 10 / ink / paper |
| Value structure | نسبة الضلمة للنور (مثلا 70% dark mids) |
| Shapes | دواير / مستطيلات حادة / أقواس؟ نسبة الزوايا |
| Materials | ورق، نحاس، زجاج، قماش، بلاستيك... مع لمعان (matte/gloss) |
| Textures | grain، paper fiber، halftone، scratches (مقدار 0-10) |
| Type | Display + Text + Arabic + Latin، أوزان، tracking |
| Layout | grid، margins، اتجاه القراءة RTL |
| Lighting | اتجاه، حرارة (K)، hard/soft |
| Motion | سرعة، easing، نوع الانتقال، فريمات (12/24 fps feel) |
| Sound/Mood | tempo، ألة مميزة |
| Don'ts | 5 حاجات ممنوعة |
| Hero frame | صورة/اسكتش واحد يمثل العالم |

## 2. اللون

### 2.1 القيمة قبل اللون (Value first)
- اشتغل grayscale الأول. لو الصورة مش مقروءة بالأبيض والأسود، اللون مش هينقذها.
- 3 قيم تكفي: dark / mid / light. المشهد = ~60% mid، ~25% dark، ~15% light (أو قلبها لـ high-key/low-key بقرار).
- اختبار: صغّر الصورة لـ 100px، أو blur عالي. لو الشكل الرئيسي لسه باين، القيمة سليمة.
- التباين الأعلى = نقطة البؤرة. حط أعلى contrast عند الحاجة المهمة بس.

### 2.2 Harmonies

| النوع | الوصف | الإحساس | استخدام |
|---|---|---|---|
| Monochrome | لون واحد بدرجات | هادي، فخم | بوستر مينيمال |
| Analogous | جيران على العجلة (30°) | مريح، طبيعي | مشاهد نيل/غروب |
| Complementary | متقابلين (180°) | صدام، طاقة | teal/orange، أزرق/ذهبي |
| Split-comp | لون + جارَي مقابله | تباين أخف | براند |
| Triadic | 120° | مرح، pop | Memphis، أطفال |
| Tetradic | 4 ألوان | غني، صعب | بس لو واحد مسيطر |

### 2.3 60-30-10
60% dominant (خلفية/جو)، 30% secondary (الأجسام الكبيرة)، 10% accent (النقطة اللي العين تروحلها). الـ accent ما يتكررش في حاجات كتير وإلا يضيع معناه.

### 2.4 Color script (فيلم/ريل طويل)
- ارسم شريط ألوان: لون سائد لكل sequence (thumbnail 1 سطر).
- ربط اللون بالقوس الدرامي: بداية (خامل/بارد) → تصاعد (تشبّع) → ذروة (accent قوي) → خاتمة (رجوع للـ dominant بس مختلف).
- غيّر لون واحد في كل انتقال كبير مش كل الألوان.
- اللون «بيوعد» الجمهور: لو ظهر الذهبي في أول ثانية، لازم يرجع.

### 2.5 دلالات اللون — ثقافية مش عالمية

| اللون | عالميا (شائع) | في السياق المصري/العربي (ملاحظات، مش قاعدة) |
|---|---|---|
| أحمر | خطر، حب، طاقة | الأهلي، الشهادة والدم، العروس (حنة وفرح)؛ سياسيا حساس حسب السياق |
| أخضر | طبيعة، أمان | الإسلام والخضرة والجنة، الزراعة والدلتا، علم باكستان/السعودية في الذهن |
| أزرق فيروزي | هدوء | الفيروز وخرزة العين (حماية)، قاشاني، مياه |
| ذهبي | رفاهية | مصر القديمة، الخط العربي والمخطوطات، ممكن يبقى «كتير» وكيتش |
| أبيض | نقاء | الكفن/الإحرام كمان؛ الجلابية، الفرح الحديث |
| أسود | حداد (غربي) | حداد في مصر كمان، بس كمان أناقة وقوة وسهرة؛ «التنين الأسود» نفسه |
| أصفر | فرحة | الصحرا والرمل؛ ممكن يوحي بغيرة/مرض في أمثال معينة |
| بنفسجي | ملكي | أقل تقليدية في التراث، يقرأ «حديث/نيون» |
| الأزرق الغامق (نيلي) | عمق | الليل، النيل، حبر المخطوطات |

نصيحة: اسأل الجمهور المستهدف. دلالة الألوان بتتغير بالجيل والطبقة والمنطقة (القاهرة ≠ صعيد ≠ الخليج).

## 4. Shape language / texture / hierarchy / gestalt

### 4.1 Shape language

| الشكل | الإحساس | مثال |
|---|---|---|
| دايرة | ود، كمال، أمان | شخصية طيبة، شمس |
| مربع | ثبات، نظام | مباني، سلطة |
| مثلث/حاد | خطر، حركة، طاقة | شرير، سهم |
| منحنى S | رشاقة، انسياب | خط عربي، نيل |
| خط أفقي | هدوء، راحة | أفق، فراغ |
| خط رأسي | قوة، عظمة | مآذن، أعمدة |
| قطري | حركة، توتر | اكشن |

كل عالم يختار نسبة: مثلا 70% منحنيات / 30% زوايا. الشخصيات والمجموعات لازم تقرأ كـ silhouette.

### 4.2 Texture & material
- الخامة تقول زمن وطبقة: ورق صحف = شعبي/قديم، معدن ملمّع = تقني، قماش خشن = ريفي.
- grain موحّد على كل حاجة (حتى الجرافيك) يلحم الطبقات مع بعض.
- حط texture في الأطراف وسيب مركز الاهتمام نظيف.
- لمعان (specular) = تأكيد. اللي بيلمع بيجذب العين.

### 4.3 Visual hierarchy
ترتيب الجذب: (1) تباين قيمة (2) حجم (3) لون مشبع (4) حركة (5) وش بشري/عين (6) موقع (7) عزل بفراغ. اختار 3 مستويات بس: Primary / Secondary / Tertiary.
- اختبار القراءة بعيون مغمضة: غمّض عينك لنص ثانية وافتح، إيه أول حاجة شفتها؟
- RTL: العين بتبدأ من اليمين فوق وتنزل لتحت-شمال. حط العنوان يمين لو عربي.

### 4.4 Gestalt

| المبدأ | معناه | استخدام |
|---|---|---|
| Proximity | القريب = مجموعة | جمّع المعلومات بالمسافة |
| Similarity | الشبه = مجموعة | نفس لون = نفس معنى |
| Closure | العين تكمل الناقص | لوجو بشكل ناقص |
| Continuity | العين تتبع خط | قود العين لـ CTA |
| Figure/Ground | شكل ضد خلفية | negative space ذكي |
| Common fate | اللي بيتحرك سوا = مجموعة | motion للعناصر المرتبطة |
| Prägnanz | العقل يبسّط | الشكل البسيط أقوى |

## 5. التراث العربي والإسلامي البصري

### 5.1 الزخرفة الهندسية (إزاي تبنيها)
1. **ابدأ بدايرة** (بالفرجار). الدايرة هي أصل كل باترن.
2. **قسّمها**: 4 أو 6 أو 8 أو 12 (أو 5 / 10 للمتقدم). 6 = تقسيم بنفس نصف القطر على المحيط. 8 = مربعين متداخلين (نجمة ثمانية).
3. **وصّل النقاط** بخطوط → تبقى شبكة (grid) من مثلثات/مربعات/سداسيات.
4. **اتبع القاعدة**: أرسم نجمة (مثلا {8/2}: وصّل كل ثاني نقطة)، بعدين اعمل **strapwork**: خطوط بتتشابك فوق/تحت (over-under) بعرض ثابت.
5. **كرّر** الوحدة (tile): مربعة أو سداسية أو معين، بحيث الأطراف تتطابق.
6. **نظّف**: وحّد عرض الخط، قرّب الزوايا، ولوّن بـ 2-3 ألوان.

كود (Python Pillow، غير متحقق منه): رسم نجمة 8 وتكرارها.
```python
from PIL import Image, ImageDraw
import math
def star(draw, cx, cy, r, n=8, skip=3, w=3, col="#C9A227"):
    pts = [(cx + r*math.cos(2*math.pi*i/n), cy + r*math.sin(2*math.pi*i/n)) for i in range(n)]
    for i in range(n):
        draw.line([pts[i], pts[(i+skip) % n]], fill=col, width=w)
im = Image.new("RGB", (1080, 1080), "#0E0E12")
d = ImageDraw.Draw(im)
step = 180
for y in range(90, 1080, step):
    for x in range(90, 1080, step):
        star(d, x, y, 80)
im.save("pattern.png")
```
في Inkscape: Edit → Clone → Create Tiled Clones للتكرار. في Blender: Array modifier أو Geometry Nodes (Instance on Points).

### 5.2 عناصر
| العنصر | الوصف | استخدام حديث |
|---|---|---|
| **المشربية** | شبكة خشب مخرّطة، تلعب بالضوء والخصوصية | ظلال pattern على وش/جدار؛ أنسب ضوء: شمس منخفضة بتعدي من فتحات |
| **القاشاني / tilework** | بلاط ملون هندسي أو نباتي (فيروزي، كوبالت، أبيض) | خلفية، transitions على شكل بلاط بيتقلب |
| **الأرابيسك / التوريق** | منحنيات نباتية متصلة بلا نهاية | إطار أو فاصل بين مشاهد |
| **المخطوطات المزخرفة (illumination)** | ذهب، لازورد، إطارات (جداول)، شمسة، ترنجة | تيتل افتتاحي، كادر ذهبي رفيع |
| **الخط كصورة** | حروف تتحول لشكل (ثلث، ديواني، كوفي، نسخ، رقعة) | حرف كبير crop كتكوين تجريدي، حبر يتكتب في المشهد |

### 5.3 الخط العربي كصورة
- الخط له شخصية: **ثلث** (فخامة)، **ديواني** (بلاط عثماني، حركة)، **كوفي** (هندسي، حديث)، **رقعة** (يومي)، **نسخ** (قراءة).
- ما تشدش الحروف (kashida مفتعلة) ولا تفصل الحروف المتصلة. الحروف العربية لازم تتصل.
- التشكيل والحروف المتراكبة (stacked) للتكوين لازم تتقرأ.
- لو الخط بيتحرك كتابة، اتبع اتجاه الكتابة الحقيقي (من اليمين، وترتيب الضربات).

### 5.4 تجنب الكيتش
- مش كل حاجة عربي = هلال + فانوس + جمل + أهرامات.
- الزخرفة تخدم الفكرة، مش لازم تتحط على كل سطح.
- ما تخلطش مصر الفرعونية + إسلامية + «ألف ليلة» في بوستر واحد من غير سبب.
- استشر مصادر أصلية: مخطوطات (متحف الفن الإسلامي بالقاهرة، دار الكتب)، مش بس stock.
- احترم الآيات والأسماء المقدسة: ما تتحطش كزينة تحت الأقدام أو على حاجة مبتذلة.

## 6. Moodboard وطريقة وصف الستايل

### Workflow
1. **اجمع** 40-60 صورة بسرعة بدون حكم (media-hunter / متاحف / أرشيف).
2. **فرّز**: احذف ما يطابقش الإحساس. حدّد الـ 12-20 الأقوى.
3. **اتنين مصادر على الأقل من برّه المجال** (فن، عمارة، طبيعة، أفيشات قديمة) عشان ما تطلعش نسخة.
4. **استخرج**: palette (eyedropper)، خطوط، خامات، composition.
5. **اكتب القواعد** تحتهم (Style Bible).
6. **اختبر** بلقطة hero واحدة قبل ما تكمل.
7. صور مرجعية = إلهام، مش نسخ. ما تنسخش شغل فنان معين.

### وصف الستايل بدقة
صيغة: **[وسيط] + [موضوع] + [إضاءة] + [لون] + [خامة] + [composition] + [عدسة/كاميرا] + [مزاج] + [ممنوعات]**

| بدل | قل |
|---|---|
| «حلو وسينمائي» | «low-key، key light من اليسار 3200K، fill خافت، teal shadows، grain 35mm، عمق ضيق f/1.8» |
| «عربي فخم» | «حبر أسود + ذهب مطفي #C9A227، خط ثلث، فراغ سلبي 60%، بدون pattern» |
| «قديم» | «ورق مصفر، طباعة مكتبية بتسريب حبر، misregistration 2px، حواف مجروحة» |
| «مودرن» | «sans هندسي، grid 12 عمود، لون accent واحد، بدون ظلال» |

استخدم: ألوان بـ HEX، أرقام (نسب، K، f-stop، fps)، أسماء خامات، «لا» صريحة. وللـ AI generators: اكتب الـ negatives كمان.

## 7. وصفات ImageMagick

> الأوامر بصيغة `magick` (v7). في PowerShell/CMD الأقواس عادية `(` `)`؛ في bash لازم `\(` `\)`. **كل الوصفات غير متحقق منها على جهاز المستخدم** — جرّب على نسخة صورة الأول وراجع النتيجة بالعين.

**Duotone** (ظلال → لون، إضاءات → لون):
```
magick in.jpg -colorspace Gray +level-colors "#0B0F2A","#F2C14E" duotone.png
```

**Gradient map** (3 ألوان):
```
magick in.jpg -colorspace Gray ( xc:"#0B0F2A" xc:"#C8352B" xc:"#F2C14E" +append -filter Cubic -resize 256x1! ) -clut gmap.png
```

**Halftone** (نقط، أبيض/أسود ملوّن):
```
magick in.jpg -colorspace Gray -ordered-dither h8x8a +level-colors "#1A1411","#F3E7C9" halftone.png
```
(`h6x6a` نقط أصغر؛ `h8x8a` نقط أكبر.)

**Film grain** (ضجيج gaussian):
```
magick in.jpg -attenuate 0.35 +noise Gaussian grain.png
```
ضجيج أحادي اللون (أنعم): `-attenuate 0.35 +noise Gaussian -modulate 100,0` على طبقة منفصلة ثم blend (متقدم).

**Posterize / Riso look** (طبقتين بحبرين + overprint):
```
magick in.jpg ( +clone -channel R -separate +channel -ordered-dither h6x6a +level-colors "#FF48B0","white" ) ( in.jpg -channel B -separate +channel -ordered-dither h6x6a +level-colors "#0078BF","white" ) -delete 0 -compose Multiply -composite -roll +2+1 riso.png
```
مبسّط وأضمن: `magick in.jpg -colorspace Gray -posterize 3 +level-colors "#1C1C1C","#F4EFE6" poster.png`. و`-roll +2+1` على طبقة واحدة بس هو اللي بيعمل misregistration (طبّقه على الطبقة الأولى قبل الدمج لو عايز دقة).

**ملاحظة ورق:** بعد أي وصفة ضيف ورق: `-compose Multiply -composite paper.jpg` (طبقة texture ورق).

## 8. Anti-kitsch checklist

- [ ] فيه فكرة واحدة مسيطرة، مش «كل حاجة حلوة سوا»؟
- [ ] عدد الألوان ≤ 5 وفيه accent واحد؟
- [ ] التأثيرات (glow, lens flare, gradient) لها سبب؟
- [ ] الرموز (هلال، أهرامات، فانوس) محتاجة فعلا؟ لو شلتها الفكرة تفضل؟
- [ ] الخط العربي حقيقي ومقروء، من غير تمطيط مفتعل؟
- [ ] فيه مساحة فاضية (negative space)؟
- [ ] التكوين بدون تماثل كامل مفتعل، ومن غير 3 مصادر ضوء متضاربة؟
- [ ] الخامات متسقة (مش ورق قديم مع chrome من غير سبب)؟
- [ ] مفيش ستوك واضح أو قالب مألوف؟
- [ ] مفيش تنميط لثقافة أو شخصيات؟
- [ ] الزخرفة في خدمة المحتوى مش بتغطي عليه؟
- [ ] لو شلت أي عنصر، هل الشغل أحسن؟ (اشيله)

## 9. نقد الإخراج الفني — 10 نقاط

| # | السؤال | علامة المشكلة |
|---|---|---|
| 1 | الفكرة تتلخص في جملة؟ | محتاج شرح كتير |
| 2 | الـ hierarchy واضح (أول/تاني/تالت)؟ | العين تايهة |

| 4 | اللون: 60-30-10 والـ accent واحد؟ | قوس قزح |
| 5 | الشكل والخامة متسقين مع الإحساس؟ | تناقض غير مقصود |
| 6 | التايبوغرافيا مقروءة وفيها شخصية؟ | خط افتراضي، اتجاه RTL غلط |
| 7 | التكوين: فراغ، توازن، قيادة العين؟ | زحمة / ركن ميت |
| 8 | الاتساق: نفس القواعد في كل الأسطح/اللقطات؟ | كل لقطة عالم |
| 9 | الأصالة: فيه توقيع مش مجرد مرجع؟ | نسخة من Pinterest |
| 10 | الاحترام والسياق الثقافي سليم؟ | تنميط/كيتش/رمز مقدس مبتذل |

**طريقة الاستخدام:** قيّم كل نقطة 0-2. تحت 14: ارجع للمفهوم. 14-17: صلّح الأضعف 3 نقاط. 18+: جاهز، شوف التفاصيل (kerning, grain, ريتم).
