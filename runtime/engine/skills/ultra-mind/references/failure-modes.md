# أخطاء النماذج اللغوية المعروفة — وإزاي تكشفها

| الخطأ | شكله | الكشف / العلاج |
|---|---|---|
| **اللغز المشهور المعدّل** | المسألة شبه لغز معروف بس بشرط متغير، والنموذج يجاوب على الأصلي | اقرا كل شرط حرفيًا واسأل: «إيه المختلف عن النسخة المشهورة؟» |
| **استبدال السؤال** | بيجاوب سؤال أسهل أو أعم من المطلوب | أعد قراءة الطلب بعد ما تخلّص: «جاوبت على **ده** بالظبط؟» |
| **العد والحروف** | عد حروف، كلمات، عناصر، أيام، فرق تواريخ | اكتب العناصر واحد واحد أو استخدم كود |
| **الحساب الذهني** | ضرب وقسمة ونسب ووحدات | كود أو تعويض عكسي |
| **الوحدات والمقاييس** | خلط ثواني/دقايق، MB/MiB، نسبة مئوية/نقطة مئوية | اكتب الوحدة جنب كل رقم |
| **الحالات الحدّية** | الحل شغّال للحالة العادية بس | جرّب 0، 1، فاضي، سالب، مكرر، أكبر قيمة |
| **اختراع مصادر** | أسماء أوراق أو روابط أو اقتباسات أو أرقام صفحات مخترعة | ماتذكرش مصدر مش متأكد منه؛ قول "حسب علمي" أو دوّر |
| **معرفة قديمة** | إصدارات، أسعار، أحداث، APIs اتغيرت | قول تاريخ المعرفة أو دوّر على الويب |
| **التملّق** | بيغيّر الإجابة الصحيحة لما المستخدم يعترض | اسأل: فيه **دليل جديد**؟ لو لأ، اثبت بأدب واشرح |
| **القفل المبكر** | أول تفسير بيبقى النهائي | ولّد فرضية بديلة واحدة على الأقل |
| **الثقة الزائدة في سلسلة طويلة** | كل خطوة 95% صح، 10 خطوات ≈ 60% | الخطوات الحرجة تتحقق لوحدها |
| **التحوّط الزائد** | الإجابة غرقانة في "ممكن" و"يعتمد" | التزم بالأرجح وقول الشرط اللي يغيّره |
| **الإسهاب** | حشو، تكرار السؤال، مقدمات | ابدأ بالنتيجة واحذف أي جملة مش بتضيف |
| **السببية من الارتباط** | «X حصل مع Y يبقى X سبب Y» | دوّر على مُربك أو سببية عكسية أو صدفة |
| **إهمال المعدل الأساسي** | تفاصيل الحالة بتطغى على الإحصائية العامة | ابدأ بالـ base rate |
| **ادعاء إن حاجة اشتغلت** | «الكود ده هيشتغل» من غير تشغيل | شغّل أو قول بوضوح إنه ماتجربش |
| **نسيان قيد في الطلب** | 5 شروط والحل بيلبّي 4 | اعمل قائمة بالقيود في الأول وراجعها في الآخر |
| **التعديل في مكان غلط** | تعديل الكود ده بيكسر حاجة تانية | دوّر على كل الاستخدامات قبل التعديل |
