# قوائم التحقق حسب نوع المخرج (Gawande: قصيرة، عند نقطة التسليم)

## رياضيات / منطق
- [ ] كل شرط في المسألة اتستخدم أو اتبرر إنه مش لازم
- [ ] الحساب اتعمل بكود أو اتراجع بطريقة تانية
- [ ] التعويض العكسي: الإجابة بتحقق المعادلة / الشروط الأصلية
- [ ] حالة صغيرة (n=1,2) بتدي نفس النتيجة
- [ ] الوحدات والإشارات والتقريب سليمين
- [ ] الإجابة معقولة في الحجم (sanity check)

## كود / باجات
- [ ] المشكلة اتعاد إنتاجها قبل الإصلاح
- [ ] السبب الجذري اتحدد، مش العَرَض بس
- [ ] الكود اتشغّل فعلًا، والاختبارات عدّت (أو اتقال بوضوح إنه ماتشغلش)
- [ ] الحالات الحدية اتجربت
- [ ] مفيش حاجة تانية اتكسرت (كل الاستخدامات اتراجعت)
- [ ] التعديل أصغر حاجة كافية

## حقائق / بحث / تحليل
- [ ] كل ادعاء مهم له مصدر أو منطق واضح
- [ ] المصادر أولية أو موثوقة، وتاريخها مناسب
- [ ] الفرضيات البديلة اتفحصت (ACH)
- [ ] الحقيقة مفصولة عن الرأي والاستنتاج
- [ ] مفيش مصدر أو رقم مخترع

## قرار / خطة / استراتيجية
- [ ] على الأقل 3 بدائل، منها "ماتعملش حاجة"
- [ ] المعايير واضحة وبأوزان
- [ ] pre-mortem: أكبر 3 أسباب للفشل ولكل واحد تخفيف
- [ ] أسوأ سيناريو مقبول؟ القرار قابل للرجوع؟
- [ ] أول خطوة ملموسة ومحددة بوقت

## تنبؤ / تقدير
- [ ] بدأت بالـ outside view (معدل أساسي)
- [ ] نطاق مش رقم واحد، أو احتمال محدد
- [ ] العوامل اللي ممكن تغيّر التقدير مكتوبة

## إبداع / تصميم
- [ ] اتولّد على الأقل 6–10 أفكار قبل الانتقاء
- [ ] الأفكار من فئات مختلفة
- [ ] الفكرة المختارة ملموسة (تفاصيل، مثال، شكل)
- [ ] بتحل المشكلة الحقيقية مش بس "حلوة"

## كتابة / شرح
- [ ] أول جملة فيها النتيجة أو الفكرة الأساسية
- [ ] مناسب لمستوى القارئ
- [ ] مثال ملموس واحد على الأقل للفكرة الصعبة
- [ ] اتشال الحشو والتكرار
- [ ] كل طلبات المستخدم اتغطت
