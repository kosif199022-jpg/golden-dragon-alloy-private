# النظريات: إزاي كل واحدة تتحوّل لخطوة تحليل

كل نظرية هنا مكتوبة كـ **فعل** مش كمعلومة. لو مش هتغيّر اللي بتعمله، ماتستخدمهاش.

## 1. الاستدلال البايزي ونسب الأرجحية (Bayes / Jaynes)
- **قبل الدليل:** حدّد احتمال مبدئي من المعدل الأساسي. أمثلة تقريبية: exe موقّع من ناشر كبير ومعروف في مساره الطبيعي ← خبيث <1%. exe جه مرفق في إيميل غريب ومضغوط ← 30-60%.
- **مع كل دليل:** اسأل «احتمال أشوف الدليل ده لو H صح ÷ احتماله لو H غلط» = LR.
  - LR تقريبية مفيدة: توقيع صالح من ناشر معروف ≈ 0.05 لـ «خبيث». إنتروبي قسم كود > 7.4 ≈ 3. استيراد `VirtualAllocEx+WriteProcessMemory+CreateRemoteThread` مع بعض ≈ 8. نص `powershell -enc` مخفي ≈ 6. اتصال بدومين عمره أيام ≈ 4.
- `omni bayes 0.05 3 8` يحسب لك. الأدلة لازم تكون **مستقلة**؛ لو اتنين بيقولوا نفس الحاجة (UPX في die وUPX في rz-bin) اعتبرهم دليل واحد.

## 2. تحليل الفرضيات المتنافسة — ACH (Richards Heuer)
1. اكتب كل الفرضيات المعقولة (بريء/أداة إدارة/أدوير/خبيث/تالف…).
2. اكتب الأدلة كصفوف.
3. علّم كل خانة: C متسق، I متناقض، N محايد.
4. **احذف** الأدلة اللي متسقة مع الكل (مالهاش قيمة تشخيصية).
5. الفرضية الأرجح = **أقل I**، مش أكتر C.
6. اسأل: لو دليل واحد طلع غلط، الحكم يتقلب؟ ← ده «الدليل الحرج»، أكّده من مصدر تاني.
`omni hyp "H1" "H2" "H3"` يطلّع الجدول.

## 3. التكذيب (Karl Popper) + Pre-mortem (Gary Klein)
- لكل استنتاج قوي، اكتب **الملاحظة اللي تكذّبه** وروح دوّر عليها. مثال: «البرنامج مابيستخدمش النت» ← دوّر على `ws2_32`/`winhttp`/`wininet`/`InternetOpen` في الاستيراد **و** في FLOSS **و** في الاستيراد الديناميكي (`GetProcAddress` + نصوص أسماء دوال).
- Pre-mortem: «بعد أسبوع اكتشفنا إن التقرير غلط. ليه؟» أشهر الإجابات: الملف كان مضغوط وحلّلنا الغلاف، أو فيه مرحلة تانية بتتنزّل، أو حلّلنا نسخة غير اللي عند المستخدم.

## 4. نظرية المعلومات (Claude Shannon)
- **الإنتروبي** بيقيس العشوائية بالبت لكل بايت (0-8):
  - < 4.5: نص، جداول، بيانات متكررة.
  - 4.5-7.0: كود عادي وموارد.
  - > 7.2: مضغوط أو متشفّر ← الكود الحقيقي مستخبي ← لازم unpack قبل ما تصدّق أي نتيجة ستاتيكية.
- **بروفايل الإنتروبي** (`entropy_profile_1MB` في probe) بيوريك الأجزاء: قفزة فجأة لـ 7.9 في آخر الملف = overlay (بيانات ملزوقة: installer، PyInstaller، payload).
- قانون: **لو الإنتروبي عالي، غياب النصوص والاستيراد مش دليل على حاجة.**

## 5. التفكير الأنظمي (Donella Meadows) + نموذج C4
- النظام = عناصر + علاقات + هدف. أهم حاجة العلاقات.
- ارسم: المستخدم ← الواجهة ← العملية ← الملفات/الريجستري/الشبكة ← السيرفرات. حدّد **حلقات التغذية الراجعة** (auto-update، persistence، retry loops).
- نقاط الرافعة: الإعدادات، والتحديث التلقائي، ومين بيتحكم في الكود اللي بيتنزّل. دي أخطر من أي دالة لوحدها.

## 6. الاستدلال السببي (Judea Pearl)
- سلّم السببية: **ارتباط** (شفت X وY مع بعض) ← **تدخّل** (غيّرت X فـY اتغيّر) ← **مضاد للواقع** (لو X ماكانش موجود، Y كان هيحصل؟).
- التحليل الستاتيكي = مستوى الارتباط. تشغيل في بيئة معزولة مع تغيير متغير واحد = مستوى التدخّل. ماتكتبش «X بيسبب Y» من الستاتيكي لوحده؛ اكتب «الكود بيشاور على إن…».

## 7. Cynefin (Dave Snowden): اختار الأسلوب حسب نوع المشكلة
- **واضح:** ملف معروف ← ابحث عن الهاش وتحقق من التوقيع وخلص.
- **معقّد:** برنامج كبير غير معروف ← خبير + أدوات + طبقات (البروتوكول الكامل).
- **مركّب (complex):** نظام بيتغيّر (موقع حي، عملية بتكلّم سيرفر) ← جرّب وراقب (probe-sense-respond)، ماتفترضش إن النتيجة النهارده هي هي بكره.
- **فوضوي:** حادثة شغالة ← اعزل الأول (افصل النت، اوقف العملية بإذن)، حلّل بعدين.

## 8. OODA (John Boyd)
لاحظ ← وجّه (الفرضيات والسياق) ← قرّر (الأداة الجاية) ← نفّذ ← ارجع لاحظ. السرعة في الدورة أهم من الكمال في أي خطوة.

## 9. نمذجة التهديدات
- **STRIDE** على كل حد ثقة: Spoofing (انتحال)، Tampering (تلاعب)، Repudiation (إنكار)، Information disclosure (تسريب)، Denial of service، Elevation of privilege.
- **Kill Chain / MITRE ATT&CK**: رتّب القدرات اللي capa طلّعها على المراحل (Initial Access ← Execution ← Persistence ← Defense Evasion ← C2 ← Exfiltration). قدرات متفرقة = أداة. سلسلة كاملة = غالبًا خبيث.
- **Diamond Model**: الخصم ← القدرة ← البنية التحتية ← الضحية. مفيد لما تربط ملف بدومينات وIPs.

## 10. الاستدلال الاستقرائي الأفضل (Abduction / Inference to the Best Explanation — Peirce)
لما الأدلة ناقصة: اختار التفسير اللي **يشرح أكتر بافتراضات أقل** (Occam) **ومع ذلك** ماتكتبوش كحقيقة، اكتبه 🟡 باحتمال.

## 11. المعايرة (Philip Tetlock)
- استخدم أرقام: 55% / 70% / 90% / 99%. «ممكن» و«غالبًا» من غير رقم ممنوعين في الحكم النهائي.
- فصل صريح: اللي **شفته** / اللي **استنتجته** / اللي **افترضته**.

## 12. حدود التحليل (Rice / Halting)
مفيش تحليل ستاتيكي يقدر يحكم 100% على سلوك أي برنامج (Rice's theorem). عشان كده: الحكم دايمًا احتمالي، ووقت التشغيل يكمّل الستاتيكي مش يستبدله.
