# أخطاء التحليل الشائعة (راجعها قبل الحكم)

| الخطأ | شكله | العلاج |
|---|---|---|
| تحليل الغلاف | capa طلّع قدرات قليلة لملف إنتروبيه 7.8 | unpack الأول؛ النتيجة الستاتيكية على ملف مضغوط مش موثوقة |
| الانحياز للتأكيد | دوّرت بس على اللي يثبت إنه خبيث | ACH: لازم فرضية «بريء» في الجدول، ودوّر على اللي يكذّب الأرجح |
| عدّ الدليل مرتين | die وrz-bin الاتنين قالوا UPX = دليلين | الأدلة من نفس المصدر = دليل واحد |
| الثقة في الامتداد | `.pdf.exe` أو `.jpg` هو فعلًا zip | `omni classify` بيعتمد على الـ magic |
| مطابقة نص = سلوك | لقيت URL في النصوص فقلت «بيكلّم السيرفر ده» | النص موجود ≠ بيُستخدم. اكتبه 🟡 لحد ما تلاقي الكود اللي بيستخدمه أو ترافيك |
| تعميم من عيّنة | فتحت 3 دوال من 4000 | قول حجم العيّنة صراحة |
| تجاهل المعدل الأساسي | علامة واحدة غريبة في ملف Microsoft موقّع ← «خبيث» | ابدأ من الـ prior وحدّثه بنسبة أرجحية |
| الخلط بين ستاتيكي وديناميكي | «البرنامج بيعمل X» من غير تشغيل | «الكود فيه قدرة X» لحد ما تتأكد وقت التشغيل |
| أمان التحليل نفسه | فكّيت أرشيف في نفس مجلد السكربتات | مجلد جديد فاضي، `python -I`، ماتشغّلش حاجة من جوّا |
| هلوسة الأوامر | كتبت flag مش موجود | `RT run <id> --help` الأول |
| تقرير طويل من غير حكم | 20 صفحة مخرجات أدوات | أول سطر = الحكم. المخرجات الخام في ملحق أو ملف |

- [ ] أول سطر فيه حكم واضح + ثقة برقم.
- [ ] كل ✅ ليه مصدر (أمر/أوفست/سطر).
- [ ] فيه فرضية بديلة اتفحصت واترفضت بسبب مكتوب.
- [ ] كل ❓ معاه الخطوة اللي تحسمه.
- [ ] مفيش ملف أصلي اتعدّل، ومفيش حاجة اتشغّلت من غير إذن.
- [ ] الأسرار مقنّعة.
