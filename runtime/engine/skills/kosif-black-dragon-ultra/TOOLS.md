# بروتوكول الأدوات الموحّد — التنين الأسود الفائق

هذا البروتوكول مبني من:
- مسح ثابت لاستيرادات **711 سكربت** في الوحدات الـ 21، بدون تشغيل أي منها.
- قوائم المستودع `requirements/*.txt`.

**المصدر الآلي:** `tools.json`. **الفحص:** `python scripts/dragon.py doctor`. **التثبيت:** `python scripts/dragon.py install <درجة>`.

## الدرجات
| الدرجة | ماذا تحوي | متى تُثبَّت |
|---|---|---|
| **system** | Python وNode وFFmpeg/ffprobe وGit وImageMagick وTesseract | دائماً، قبل أي عمل وسائط |
| **core** | حوالي 70 مكتبة Python خفيفة تستوردها السكربتات فعلاً، مع متصفح Chromium لـ Playwright | دائماً |
| **node** | حزم `requirements/node.txt` (Remotion وHyperFrames وGSAP وThree وPlaywright وPuppeteer…) داخل `node_modules` في المستودع، بدون تعديل `package.json` | لأعمال الموشن والمواقع |
| **heavy** | PyTorch (نسخة CPU)، وDiffusers، وWhisperX، وDemucs، وMediaPipe، وspaCy، وBlender (bpy)، وManim، وLaMa… | عند الحاجة فقط، بموافقة المستخدم (عدة جيجابايت) |
| **agents** | حزم برمجية لخدمات مدفوعة: Anthropic وTogether وFal وGemini وLangGraph وDSPy… | فقط بموافقة صريحة ومفتاح API من المستخدم (`--yes`) |

## قواعد
1. **الفحص في كل جلسة:** أول مرة في الجلسة شغّل `doctor`. وقبل استخدام وحدة شغّل `needs <الوحدة>`، فهو يعرض ما تستورده تلك الوحدة فعلاً وما ينقصها.
2. **التثبيت الذكي:** يحاول `install` تثبيت كل الحزم دفعة واحدة. إن فشلت حزمة يعيد المحاولة حزمة حزمة، فلا توقف حزمة واحدة معطّلة الباقي.
3. **ما لا يُثبَّت تلقائياً:**
   - `DaVinciResolveScript` يأتي مع برنامج DaVinci Resolve.
   - `bmesh` و`mathutils` تأتيان مع Blender.
   - `words_convert` أداة محلية.
4. **مكتبات تحتاج برامج نظام:**
   - `cairosvg` و`weasyprint` تحتاجان مكتبات GTK/Cairo على Windows.
   - `pytesseract` تحتاج Tesseract.
   - `pydub` و`moviepy` تحتاجان FFmpeg.
   - إن ظهرت المكتبة مثبّتة لكنها فشلت عند التشغيل، ثبّت برنامج النظام المذكور.
5. **تعارض معروف:** `rembg` و`scikit-image` تتطلبان `networkx` بنسخة 3، و`pycel` تتطلب نسخة أقل من 2.7. إن احتجت `pycel` فضعها في بيئة افتراضية منفصلة.
6. **قراءة النص العربي (Tesseract):**
   - اللغة العربية `ara` مثبّتة.
   - الخط الضخم (حوالي 80 بكسل أو أكثر) يعطي نتيجة فارغة. صغّر الصورة حتى يصير ارتفاع النص قرابة 30–50 بكسل، ثم استخدم `--psm 6` لفقرة أو `--psm 7` لسطر واحد.
   - تم الاختبار: تطابق 100% بعد التصغير، و0% قبله.
   - إذا احتجت دقة أعلى فهناك النموذج الأدق `tessdata_best/ara` (12.6MB) من مستودع tesseract-ocr الرسمي.
7. **أبداً:** لا تنزّل أدوات من مواقع غير رسمية، ولا برامج مكرّكة، ولا تستدعِ خدمة مدفوعة بدون إذن.
