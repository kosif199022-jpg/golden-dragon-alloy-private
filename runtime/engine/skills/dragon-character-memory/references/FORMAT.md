# صيغة `character_memory.json` (format: `dragon-character-memory/1`)

كل الأطوال بالبكسل في مقاس الفيديو المصدر. كل الزوايا بالدرجات، في إحداثيات الصورة (x يمين، y تحت)، فـ 90° = لتحت.

| القسم | فيه إيه |
|---|---|
| `source` | الفيديو، عدد الفريمات، fps، المقاس، المدة |
| `identity.palette` | لون كل دور: torso, head, hair, mouth, arm, leg, eye, pupil |
| `identity.proportions` | النِسب مقسومة على **ارتفاع الجسم** (`torso_height_px`): ارتفاع وعرض الرأس، عرض الجسم، طول الذراع والرجل، الطول الكلي |
| `identity.ground_y_px` | خط الأرض في المصدر (أسفل الرجلين) |
| `parts.<اسم>` | `parent`، `color`، `z` (ترتيب الرسم)، `template` (مضلع في إحداثيات الجزء)، `template_frame` (الفريم اللي اتاخد منه)، `confidence` |
| `parts.<طرف>` | زيادة: `joint_in_parent` (المفصل في إحداثيات الجسم)، `joint_std_px` (ثبات القياس)، `length`، `thickness`، `rest_angle` |
| `parts.head` | `joint_in_parent` (الرقبة)، `center_from_joint`، `size` |
| `layers` | `[z, اسم]` مرتبة من ورا لقدام |
| `expressions.eyes` / `.mouth` | لكل حالة اتشافت: `observed`، `frames_seen`، `source_frame`، `shapes` (مضلعات في إحداثيات الرأس)، `shape_source` |
| `poses` | وضعيات مفتاحية اتشافت (rest، arm_raised) بزوايا كل طرف و`source_frame` |
| `clips.walk_cycle` | دورة مشي واحدة: `source_frames`، `period_s`، `stride_px`، `direction`، و16 مرحلة لزوايا الأطراف + اهتزاز الجسم |
| `clips.wave` | التلويحة: الذراع، 24 عيّنة لزاويتها ولميل الرأس، وشكل الفم الغالب |
| `timeline` | مقاطع بالترتيب: `action` (idle، walk، wave، blink)، من فريم لفريم ومن ثانية لثانية |
| `pose_track[]` | حالة الهيكل في كل فريم: `x, y, torso, head, arm_L, arm_R, leg_L, leg_R, eyes, mouth` + `interpolated` (الأجزاء اللي زاويتها متستكملة في الفريم ده) |
| `confidence` | متوسط ظهور كل جزء، عدد فريمات الاختفاء والتغطية الجزئية، عدد الزوايا المتستكملة، ودليل ترتيب الطبقات |
| `synthesized` | ملاحظة ثابتة: الملف مافيهوش حاجة مخترعة |

## إحداثيات القوالب
- **الجسم:** الأصل = مركزه، ومتلفوف عكس زاويته (واقف مستقيم).
- **الطرف:** الأصل = المفصل، ومحور x ماشي على طول الطرف. للرسم: لف القالب بـ (زاوية الطرف + زاوية الجسم) وحطه عند المفصل.
- **الرأس والشعر والعينين والفم:** الأصل = مركز الرأس، ومتلفوفين عكس (زاوية الجسم + ميل الرأس).

## الثقة
- `confidence` للجزء = المساحة الظاهرة ÷ مساحته الكاملة (للأطراف: نسبة القالب اللي لقى لونه).
- تحت 0.5: الزاوية في الفريم ده بتتستكمل من الفريمات اللي حواليه، ومكتوبة في `interpolated`.
- ميل الرأس بيتستكمل لو تغطية القالب أقل من 0.93 أو فيه عين مستخبية.

## اللي مش في الملف
- بكسلات الفيديو (مفيش صور)، ولا الخلفية.
- أي وضعية أو تعبير ماتشافش. دول بيتعملوا وقت `animate` وبيتكتبوا في `new_scene_report.json` كـ `synthesized`.
