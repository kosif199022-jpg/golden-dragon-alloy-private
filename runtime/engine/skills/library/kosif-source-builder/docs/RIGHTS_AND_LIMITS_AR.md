# التراخيص والحدود

1. الأرشيف يتضمن **شيفرة KOSIF المساعدة الجديدة** فقط، وقائمة روابط GitHub الأصلية. ليس نسخة كاملة من المستودعات التي طورتها سابقًا أو من الأدوات مفتوحة المصدر المذكورة.
2. كل مستودع تابع لجهة أخرى يبقى مملوكًا لأصحابه ويخضع لشروط LICENSE الموجودة فيه. لا تفترض السماح بالاستخدام التجاري أو إعادة التوزيع لمجرد نشره على GitHub.
3. المستودعات الخاصة لا يمكن جلبها إلا بترخيص دخول المستخدم؛ لا تحفظ مفاتيح API أو GH tokens في الأرشيف.
4. تنزيل الكود لا يعني التثبيت والتشغيل. Blender وFFmpeg وOBS قد يحتاجون حزم رسمية منفصلة؛ أدوات AI قد تحتاج GPU وذاكرة كبيرة وتنزيل أوزان متعددة الجيجابايت.
5. حالة فحص رابط أحد المستودعات لا تضمن استمراره؛ ملف الفهرس نقطة انطلاق ويمكن تحديثه.
6. المخرجات التجريبية لا تمنح حقوق استخدام أي موسيقى أو مقاطع مرخصة.
