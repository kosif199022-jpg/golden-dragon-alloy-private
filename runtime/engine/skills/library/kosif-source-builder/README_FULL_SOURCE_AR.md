# KOSIF — تجميع الشيفرات الأصلية بالكامل

**توضيح مهم:** الملف ZIP الحالي هو **حزمة بناء وتجميع** للشيفرات، وليس أرشيف الشيفرات الأصلية لـ44 مستودعاً. يلزم تنزيل المستودعات من GitHub، لأن البيئة التي أنشأت هذه الحزمة لا تسمح بالوصول المباشر إلى GitHub ولا يمكنها جلب النسخ الكاملة للمستودعات الخاصة. **لا تدّعي هذه الحزمة أنها تحتوي الآن على الشيفرات الخارجية.**

## إنشاء ملف جميع الشيفرات بنقرة واحدة (Windows)

1. ثبّت Python 3 وGit، وصِل الإنترنت، وسجّل دخول GitHub على جهازك إذا كنت تريد تضمين المستودعات الخاصة. للحسابات الخاصة يمكن استخدام `gh auth login` و`gh auth setup-git` بعد تثبيت GitHub CLI.
2. فك ضغط `KOSIF_SOURCE_BUILDER.zip`.
3. افتح مجلد `KOSIF` وانقر مرتين على **`BUILD_FULL_SOURCE.cmd`**.
4. بعد تنزيل **كافة** المستودعات بنجاح، يُنشئ البرنامج `output/KOSIF_ALL_SOURCE.zip` ويحتوي على **ملفات المصدر الفعلية** لجميع المستودعات المختارة، وبيانات المصدر، وSHA256 وتقرير نسخ المستودعات.
5. إذا تعذر تنزيل أي مشروع، لا يصدر اسم `KOSIF_ALL_SOURCE.zip` مضللًا؛ يحفظ تقرير الأخطاء ويتيح إعادة التشغيل.

## على Linux / macOS

```bash
bash BUILD_FULL_SOURCE.sh
```

## تخصيص التجميع

```bash
# شيفرات مشاريع KOSIF وحدها
python build_full_source.py --group own

# جميع مستودعات التصوير والمونتاج والفيديو
python build_full_source.py --group all

# تحديث المستودعات التي تم تنزيلها سابقاً
python build_full_source.py --group all --update

# تضمين التاريخ الكامل لـ Git أيضاً (زيادة كبيرة في الحجم)
python build_full_source.py --group all --preserve-history --include-git

# تنزيل LFS إن كان متوفرًا (قد يكون ضخمًا جدًا)
python build_full_source.py --group all --with-lfs

# إخراج نسخة جزئية مع وسم INCOMPLETE إذا فشلت بعض المستودعات
python build_full_source.py --group all --allow-incomplete
```

### ما معنى كاملة؟

- المقصود: جميع ملفات الشيفرة الموجودة في فروع Git التي تُنزّل بنجاح، ومع المستودعات الفرعية Submodules (ما لم تستخدم `--no-submodules`).
- ليست بالضرورة كل **إصدارات Git السابقة** إلا إذا استخدمت `--preserve-history --include-git`.
- لا تتضمن تلقائيًا اعتماديات npm/pip المُنزّلة خارجيًا، تطبيقات جاهزة (مثل Blender وFFmpeg)، ملفات فيديو المخزون، أو أوزان نماذج AI الضخمة. لإحضار الملفات المُدارة بـ Git LFS استخدم `--with-lfs`.
- قد تكون الملفات المخفية ضمن الشيفرة حاوية على أمثلة تكوين؛ افحصها قبل نشر أي نسخة. لا ترفع مفاتيح API أو بيانات سرية.
- الأداة لا تشغّل أو تثبّت شيفرات المستودعات؛ تنزّلها وتضغطها فقط.
- التراخيص الأصلية لمؤلفي المستودعات محفوظة دون تعديل. راجع تراخيص كل مشروع قبل إعادة التوزيع تجاريًا.
- بعض أسماء المستودعات قد تكون خاصة أو نُقلت أو حُذفت؛ حينها يظهر ذلك في التقرير ولا تدعي الحزمة الشمول.

### لماذا يستغرق التنزيل مساحة ووقتًا؟

44 مستودعاً منها مشاريع كبيرة جدًا. يجب توفير مساحة قرص كافية للنسخ غير المضغوطة إضافة إلى ملف ZIP النهائي، مع اتصال إنترنت جيد. شفرات مثل Blender وOpenCV ليست مجرد ملف Python صغير. الدليل يتيح إعادة المحاولة بدل تنزيل جميع المشاريع من البداية.
