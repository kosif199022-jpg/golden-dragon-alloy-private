# 🦅 الطائر الذهبي — جوه التنين الأحمر

نفس قدرات تطبيق «الطائر الذهبي»، من الترمنال أو من أي محادثة. الأمر `$R gold` بيشغّل **نفس** `golden_tools.py` اللي التطبيق بيشحنه (`apps/golden-bird/app/golden_tools.py`)، ونفس الكتالوجين (`apps/golden-bird/app/golden/`)، فالنتايج واحدة.

`$R` = `python -X utf8 scripts/rd.py` من جذر التنين الأحمر.

## الأوامر
| الأمر | بيعمل إيه |
|---|---|
| `$R gold protocol` | بروتوكول الذهب (10 قواعد): قبل ما تبني، وإنت شغّال، وقبل «خلص» |
| `$R gold where` | الكتالوج فين، وكام برنامج متفكوك، وإيه اللي شغّال على الجهاز ده |
| `$R gold lib find "<كلمات>"` (`--limit N`) | دوّر في 154 مكتبة. بيفهم عربي («انيميشن»، «جزيئات»، «ثري دي»، «شيدر»، «كابشن») |
| `$R gold lib show ID` | الرخصة، والتجاري مسموح ولا لأ، والحالة، والملف الجاهز، والمصدر |
| `$R gold lib kit <مجلد الشغل> ID…` | ينسخ النسخة الجاهزة لـ `vendor/ID/` + `LICENSES.md`، ويطبع وسوم `<script>`. مكتبات ES module (three-js) بيتنسخ معاها اللي بتستورده (`three.core.js`) |
| `$R gold studio list` / `show ID` | البرامج العشرة بحالتها، وأمر كل برنامج وأمثلته وتنبيهاته من دليله |
| `$R gold studio install ID --yes` | **بموافقة:** يفحص بصمة الأرشيف ويفكّه بـ 7-Zip في `%USERPROFILE%\GoldenBird\studio\` (مابيشغّلش البرنامج). من غير `--yes` بيقول هيعمل إيه بس |
| `$R gold studio cmd ID [args…]` | يطبع الأمر الكامل للبرنامج المتفكوك. التشغيل نفسه بموافقة، وعلى عيّنة صغيرة الأول |
| `$R gold sync SCRIPT.txt WORDS.json OUT_DIR [--fps 30]` | نفس أداة التطبيق: `sync.json` (كل علامة بالثانية وبالفريم) + `captions.srt` |
| `$R gold selftest` | 20 فحص من غير نت ومن غير تشغيل أي برنامج |

## إمتى تستخدمه
- **قبل أي موشن بالكود:** `lib find` الأول. لو فيه مكتبة جاهزة `✓` استخدمها بـ `kit`، بدل كود جديد أو CDN.
- **بق شخصية على تعليق صوتي:** `studio show rhubarb` (للعربي `-r phonetic`)، وبعدها install بموافقة.
- **ضغط وتحويل فيديو بإعدادات جاهزة:** `studio show handbrakecli`. **رندر مشهد Tahoma2D من غير واجهة:** `tcomposer`. **تفريغ من غير بايثون:** `whisper-cli` (من غير موديل، لازم تجيبه).
- **التزامن:** `$R sync script` هو الكامل (كاريوكي ASS، وأحداث، و`[مكتوب|متقال]`). من v2.13 بيستخدم نفس محاذاة DP بتاعة الذهبي. `$R gold sync` موجود عشان ناتجه يطابق أداة التطبيق `speech_sync`.

## الرخص (قبل أي شغل تجاري)
الكتالوج فيه خانة `commercial_ok` لكل مكتبة: 108 `yes`، و23 `conditional`، و10 `copyleft`، و6 `unknown`، و4 `non-commercial`، و3 `no`. أي حاجة غير `yes` قولها لصاحب الشغل **قبل** ما تبني عليها. `kit` بيكتب ⚠ جنبها لوحده. وبرامج الاستوديو فيها GPL (HandBrake، Synfig، Pencil2D، Shotcut): استخدامها كبرامج مسموح، بس توزيعها جوه منتج مقفول لأ.

## اللي اتأكد واللي لأ
- ✅ بصمة كل أرشيف اتسجّلت وقت التحليل، و`install` بيرفض لو البصمة اتغيّرت (`selftest` بيختبرها).
- ✅ ملفات `.cmd` بترفض `& | ^ < > % "` في المعاملات (BatBadBut).
- ✅ `kit` بينسخ من جوه مجلد المكتبات بس.
- ✅ اتجرّب على لابتوب صاحب الشغل: `kit` لـ gsap وlottie-web وthree-js، وصفحة HTML اترندرت بيهم في Chromium والنت مقفول (مفيش ولا طلب برّه الجهاز)، والـ seek ثابت (0 ← 0.51 ← 1).
- ⚠ **ES module من `file://`:** كروم العادي بيمنعه (CORS). محرك التنين (`render.cjs`) بيفتح الصفحة بـ `--allow-file-access-from-files` فبيشتغل، وكمان سيرفر محلي (`python -m http.server`). اتقاس التلاتة.
- ✅ **three.js أوفلاين** (اتصلّح 2026-11-14): `kit` كان بينسخ `three.module.js` من غير `three.core.js`، فالفيلم كان بيرجع 404. دلوقتي `lib_kit` نفسه (في التطبيق والمهارة) بيتتبّع الـ imports النسبية، وأي import برّه فولدر المكتبة بيتقال كفشل. التطبيق المتثبت بياخد التصليح بعد البناء الجاي وزرار «حدّث دلوقتي».
- ❓ برامج الاستوديو اتحلّلت تحليل ثابت بس (README ونصوص البرنامج وGhidra). ولا برنامج اتشغّل لحد دلوقتي.
- 🖥 `kit` و`install` محتاجين مجلد «مهارات» على لابتوب صاحب الشغل. في claude.ai أو السحابة، `find` و`show` و`sync` و`protocol` بس اللي بيشتغلوا.
