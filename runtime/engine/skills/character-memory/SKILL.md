# Dragon Character Memory & Auto Rotoscope

`$C` = `python -X utf8 scripts/charmem_cli.py` (أو من التنين: `rd.py character …`). محلي بالكامل: numpy وOpenCV وscikit-image وcairosvg وffmpeg. مفيش شبكة ولا GPU ولا نماذج.

## الأوامر
| الأمر | بيعمل إيه | الناتج |
|---|---|---|
| `$C doctor` | يفحص المكتبات وffmpeg | DOCTOR OK |
| `$C demo OUT` | التجربة كاملة على «تمتم» (شخصية أصلية)، حوالي 12 دقيقة | كل المجلدات تحت |
| `$C extract VIDEO WORK` | كل فريم PNG (من غير تكرار ولا إسقاط) + توقيته من ffprobe + SHA-256 | `WORK/frames`، `timing.json` |
| `$C analyze WORK [--gt gt.json]` | باليتة، أجزاء، مفاصل، وش، اختفاء، طبقات | `WORK/track.json` |
| `$C redraw WORK` | SVG لكل فريم + فيديو إعادة الرسم + فيديو مقارنة + الأرقام | `03_redraw/` |
| `$C memory WORK [--out F]` | ذاكرة الشخصية | `character_memory.json` |
| `$C animate MEM "<أمر>" OUT` | مشهد جديد من الذاكرة بس | `new_scene.mp4`، `scene_script.json` |
| `$C edit MEM --expression laugh --set mouth_w=0.45 --out NEW` | تعديل تعبير أو إضافة واحد مولّد | ذاكرة جديدة |
| `$C export MEM OUT` | SVG للوقفة + هيكل عظام/خانات/أشكال | `character_rest.svg`، `character_skeleton.json` |
| `python -X utf8 tests/test_charmem.py OUT` | 10 مجموعات اختبار، كل عتبة مكتوبة مسبقًا | `OUT/tests_report.json` |

## إزاي بيشتغل (اقرا قبل ما تغيّر حاجة)
1. **السيلويت من الخط الخارجي** (الحلقة الغامقة المقفولة). الخلفية = متوسط البكسلات **برّه** السيلويت في كل فريم. الوسيط اتلوّث لما الشخصية وقفت نص الفيلم في مكان واحد.
2. **الباليتة:** k-means في Lab، وبعدها تمريرة تانية للألوان النادرة: كتل ماحدش من الألوان بيفسّرها (البُق المفتوح بيظهر في 20% من الفريمات بس).
3. **المعايرة على أول فريم** (لازم يبقى وقفة مقروءة، وده العرف في الروتوسكوب): كل جزء بياخد لون ومكان من الهندسة.
4. **التتبّع:** توقّع بالسرعة + الحجم. لو جزأين من نفس اللون اتلزقوا → فصل بـ 2-means. لو جزء مالوش كتلة → مختفي، ومفاصله تتكمّل وتتعلّم inferred/interpolated.
5. **المفاصل عند محاور الدوران:**
   - الكتف = طرف «الخط المركزي» المدوّر + نص عرض الدراع.
   - الرسغ والكاحل = ملتقى ألوانين.
   - الكوع والركبة = نسبة **متعلَّمة من الفريمات اللي المفصل فيها متني** + مزج ناعم مع نقطة الانثناء.
   - الورك تحت الشورت = امتداد الوتر لخط الحوض (افتراض مكتوب).
6. **الوش في إطار الراس:** «فوق» = أقرب محور للرأسي، مش الأطول. الراس بالكاب مدوّرة، والمحور الأطول لفّ الوش 90° في أول نسخة.
7. **إعادة الرسم:** كل لون path بحدود من المربعات الزاحفة عند 0.5، فالألوان المتجاورة بتشارك نفس الحد تحت البكسل. بكسلات الحواف بتاخد أقرب لون. القياس: 29 dB مقابل الأصل اللي من غير ضغط (كونتور البكسل + تكبير كان 23 dB).

## اللي اتقاس على «تمتم» (تفاصيل وصور: `references/RESULTS.md`)
- **إعادة الرسم (240 فريم):**
  - IoU القناع 0.9987 (أسوأ فريم 0.998).
  - اتفاق الألوان 0.976.
  - PSNR 28.93 dB (أسوأ فريم 27.69).
  - SSIM 0.960.
  - ΔE 3.5.
- **التتبّع مقابل الحقيقة:**
  - وسيط المفاصل الظاهرة 5.23 بكسل (2% من الراس).
  - اختفاء الإيد: دقة 1.0 واسترجاع 1.0 على 19 فريم.
- **التعبيرات:** 98.3% صح.
- **الدورات:** المشي 0.733 ث (المصمَّم 0.76)، والسلام 0.433 (0.455)، والضحك 0.333 (0.333).
- **الاختبارات:** 34 من 35 ناجحين (`tests/test_charmem.py`). الفاشل T8b: طول الفخد اليمين اللي اتعلّم تاني من فيديو المشهد الجديد طلع أقصر 16.3%، والحد 12%. السبب إن القعدة المولَّدة بتقصّر الفخد (منظور من قدّام)، والمحلّل بيحسب طول العضمة بالوسيط. جرّبنا نحسبها بالمئين 80: الفخد بقى غلطه 4–7%، بس الساق بقى 20–41%، فاترفض الحل ده. الحد ماتغيّرش، والاختبار سايبينه فاشل وموثّق.

## الحدود (قولها لصاحب الشغل قبل ما تبدأ)
- شخصية واحدة، من قدّام، بألوان مسطحة وخط خارجي غامق واحد، على خلفية ثابتة، والكاميرا ثابتة.
- الأجزاء المستخبية (إيد ورا الراس) مكانها **مستنتج مش مقاس**. اتعلّم كده، وغلطه أكبر بكتير.
- اللون نفسه لجزأين في نفس الجنب (زي جلد الوش والرجلين) بيتفرّق بالمكان. شخصية بتلف أو بتتقلب محتاجة شغل تاني.
- فيديو لشخصية محمية بحقوق: لأ. التجربة على شخصيات أصلية أو بتاعة صاحب الشغل.
