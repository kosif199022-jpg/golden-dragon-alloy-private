# حلقة التعلم من الخطأ

النموذج مابيتعلمش من نفسه بين الجلسات — أوزانه ثابتة. اللي بيخليه "يتعلم" هو **سجل دروس خارجي** بيتقرا في أول كل مهمة. ده نفس مبدأ Reflexion (Shinn et al. 2023): تأمل لفظي في خطأ **ملموس** يتحفظ ويرجع يتحقن في المحاولة الجاية. ومن الكتب: Matthew Syed — Black Box Thinking (الطيران اتحسّن عشان كل حادثة بتتحلل وتتسجل)، وAfter-Action Review في الجيش الأمريكي (كان المتوقع إيه؟ حصل إيه؟ ليه الفرق؟ هنعمل إيه المرة الجاية؟).

## السجل
- الملف: `~/.claude/expert-council/lessons.jsonl` (برة مجلد المهارة عشان مايتمسحش مع التحديث).
- الأداة: `python scripts/lessons.py` (add / search / list / hit / stats / export).

## امتى تسجّل درس (إجباري)
1. **المستخدم صحّحك** أو رفض ناتج ("لا مش كده"، "غلط"، "مش ده اللي طلبته").
2. **أداة كشفت غلطة** (الرندر طلع بمدة غلط، الصوت -9 LUFS بدل -14، الكود فشل، الفريم فيه لوجو).
3. **افتراض طلع غلط** (فاكر إن الأداة بتدعم فلاج معين وطلع لأ).
4. **حل غير متوقع نجح** (درس إيجابي: "X اشتغل أحسن من Y في الحالة Z").

## إزاي تكتب درس كويس (After-Action Review)
- `--trigger`: **امتى** الدرس ده ينطبق (الموقف اللي يفكرك بيه). ده أهم حقل للبحث.
- `--mistake`: اللي حصل بالظبط، بأرقام لو فيه.
- `--lesson`: **قاعدة قابلة للتنفيذ** تبدأ بفعل. مش "لازم أكون أدق"، لكن "شغّل loudnorm two-pass وقيس بـ ffprobe قبل التسليم".
- `--severity high` لو الغلطة كلّفت وقت كبير أو وصلت للمستخدم.
- `--source user` لو المستخدم هو اللي كشفها.

مثال:
```
python scripts/lessons.py add --domain editing --source user --severity high \
  --trigger "ريلز بأغنية وطنية فيها كلام" \
  --mistake "قطعت على البيت بس الكلام اتقص في نص الكلمة" \
  --lesson "في القطع على موسيقى فيها غنا، قدّم القطع لنهاية الكلمة أو أول نفس، مش على البيت الحرفي"
```

## امتى تقرا الدروس
- **أول المهمة:** `search "<وصف المهمة>" --domain <المجال>`. الدروس اللي تطلع تبقى **قيود** قدام المجلس، والمتشكك يتأكد إنها اتطبقت.
- لو درس اتطبق ونفع: `hit <id>` (بيرفع وزنه).
- قبل مشروع كبير: `export --domain <المجال>` وحطه في brief الوكلاء.

## صيانة
- درس اتكرر بنفس الصياغة → الأداة بتقوّيه بدل ما تكرره.
- لو درس طلع غلط أو اتجاوزه الزمن: قول للمستخدم واقترح تعديله (ماتمسحش السجل من غير إذن).
- لو المجال فيه 10+ دروس عالية الخطورة، اقترح على المستخدم ترقيتها لقواعد داخل ملف المجال نفسه.
