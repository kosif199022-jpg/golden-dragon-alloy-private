# 💭 التفكير المرئي (مستخرج من التنين الأسود / التنين الذهبي)

التنين بيبان إنه «بيفكّر» بطبقتين مختلفتين. الاتنين لازم يتفهموا صح، علشان ماتوعدش بحاجة مش موجودة:

| الطبقة | هي إيه | مين بيتحكم فيها |
|---|---|---|
| **1. ملخص التفكير الحقيقي** | الموديل بيفكّر قبل ما يرد، والـ API بيرجّع **ملخص** مقروء للتفكير ده (عمره ما بيرجّع التفكير الخام كامل). | إعداد، مش كلام في البرومبت |
| **2. التفكير بصوت عالي** | سطور قصيرة بيكتبها الموديل في الرد نفسه قبل كل خطوة: فهمت إيه، هعمل إيه وليه، إيه اللي اتقاس. | المهارة دي (بروتوكول تحت) |

## الطبقة 1: شغّل ملخص التفكير الحقيقي

**في الموديلات الجديدة (Opus 5.5 وSonnet 5.5 وFable 5.2) الافتراضي `omitted`:** التفكير بيحصل وبيتحسب، بس بيوصل فاضي. لازم تطلب الملخص صريح:

- **Claude Code (التطبيق ده / الترمنال):** في `~/.claude/settings.json` حط
  ```json
  { "showThinkingSummaries": true }
  ```
  ده إعداد رسمي موجود في Claude Code («Request API-side thinking summaries and show them in the conversation and in the transcript view (ctrl+o)»). اتأكدت منه من ملف `claude.exe` نفسه على الجهاز. الإعداد بيشتغل من **أول جلسة جديدة** بعده، مش في الجلسة المفتوحة.
- **Claude Code من سطر الأوامر / من تطبيق:** `claude -p ... --thinking-display summarized`. ده اللي التنين الذهبي بيعمله في `app.py` (دالة `cc_thinking_flag` بتدوّر على الخيار جوه الـ exe الأول، لأنه مش ظاهر في `--help`).
- **الـ API مباشرة (Python):**
  ```python
  client.messages.stream(model="claude-opus-5-5", max_tokens=16000,
      thinking={"type": "adaptive", "display": "summarized"},
      output_config={"effort": "high"}, messages=msgs)
  # الأحداث: content_block_delta بنوع thinking_delta  ← اعرضها في صندوق «💭 بيفكّر دلوقتي…»
  #          وأول text_delta  ← اطوي الصندوق واكتب «💭 فكّر N ث»
  ```
  أي نداء فيه `thinking={"type": "adaptive"}` من غير `display` هيرجّع التفكير فاضي.

**الواجهة (زي التنين):** صندوق `<details>` مفتوح وعنوانه «💭 بيفكّر دلوقتي…»، النص بيتضاف حتة حتة، ولما الرد يبدأ الصندوق يتقفل ويبقى عنوانه «💭 فكّر N ث». ومفتاح «💭 اعرض التفكير» يقفل ويفتح الطلب نفسه، مش العرض بس.

## الطبقة 2: بروتوكول «فكّر بصوت عالي»

ده اللي يتنفذ في أي محادثة لما المهارة دي تشتغل. الهدف: صاحب الشغل يشوف اتجاهك بدري ويصحّحك قبل ما الوقت يتصرف. مش الهدف إنك تكتب مقال.

1. **أول الشغل، سطر فهم واحد بالعربي:** «💭 فهمت: … · التسليم: … · هعرف إنه خلص لما: …». لو في غموض حقيقي اسأل سؤال واحد بس، أو احسمه من الملفات.
2. **قبل كل خطوة تقيلة** (أمر طويل، تعديل ملف، رندر، تنزيل، وكلاء): سطر واحد «💭 هعمل كذا علشان كذا». السبب مهم أكتر من الوصف.
3. **لما تختار بين طرق:** «💭 قدامي X وY، اخترت X لأن …». طريقين أو تلاتة بالكتير.
4. **بعد أي نتيجة مهمة:** «💭 اتقاس: …» أو «💭 الفرضية طلعت غلط، هغيّر لـ …». قول الغلط صريح.
5. **فرّق بين الدليل والتخمين:** ✅ اتقاس / 🟡 استنتاج / ❓ مش معروف ومعاه الخطوة اللي تحسمه.
6. **ماتكتبش:** تفكير خام طويل، أو تكرار لنفس السطر، أو كلام عن نفسك. سطر لكل خطوة، وأقصى 25 كلمة للسطر.
7. **اللغة:** التقني (أوامر، أرقام، خيارات برامج) بالإنجليزي جوه backticks، والشرح بالعربي المصري. أول مصطلح تقني اكتبه بالإنجليزي بين قوسين.

**مثال:**
> 💭 فهمت: عايز تبحث في المحادثات وتثبّت محادثات · التسليم: التطبيق بالميزتين · هعرف إنه خلص لما أجرّبهم فعلًا.
> 💭 الكود متولّد من سكربت، فهعدّل السكربت مش الملف الناتج علشان التعديل مايتمسحش في التوليد الجاي.
> 💭 اتقاس: البحث لقى 42 محادثة لـ «اول مره» و42 لـ «أول مرة»، نفس النتيجة ✅.

## الإضافة في تطبيق تاني

- **تطبيق Claude ده (Code tab):** المهارة متثبتة في `~/.claude/skills/visible-thinking`، و`showThinkingSummaries: true` في `~/.claude/settings.json`. افتح محادثة جديدة.
- **claude.ai (الويب/الموبايل):** ارفع ملف `visible-thinking.zip` من الإعدادات ← Capabilities ← Skills.
- **تطبيقك الخاص:** الطبقة 1 بالكود اللي فوق، والطبقة 2 بإنك تحط قسم «البروتوكول» ده في برومبت النظام.
