# 5 أمثلة كاملة: من الطلب للتسليم

كل مثال فيه: الطلب، وقرار الكارت (`plan.py card`)، والرد الأول بالظبط، واللي بيحصل بعد كده. القرارات هنا هي اللي السكربت طلّعها فعلًا.

## المحتويات
1. طلب واضح: نفّذ على طول (L1)
2. ريل غامض: سؤال واحد بكارت، وتعارض بعد الإجابة (L2)
3. قرار: توصية مبدئية + سؤالين (L2)
4. كيبورد إنجليزي: فك وسؤال واحد
5. «نفّذ انت اللي تشوفه»: صفر أسئلة

---

## 1. طلب واضح: نفّذ على طول

**الطلب:** «نزّل الفيديو ده https://www.youtube.com/watch?v=abc123»

**الكارت:** تحميل · L1 · القرار ▶️ go · المصدر ✅، والجودة 🟡 أعلى جودة mp4، والجزء 🟡 كله.

**الرد الأول:**
```
فهمت إنك عايز: تنزّل الفيديو ده بأعلى جودة.
هعمل:
- أشوف الصيغ المتاحة (yt-dlp -F) وأختار الأعلى
- أنزّله وأقيس دقته ومدته
- أسجّل المصدر في sources.txt
الناتج: mp4 على سطح المكتب · ⏱ ~2–5 د
افتراضات: أعلى جودة متاحة، الفيديو كله.
```
وبعدها تنفيذ على طول. مفيش أسئلة لأن مفيش بند خطره ≥ 4.

**التسليم:**
```
C:\Users\cinde\OneDrive\Desktop\<اسم الفيديو>.mp4
- 1920×1080 · 25fps · 4:12 · 86MB (اتقاس بـ verify_media)
- المصدر اتسجّل في sources.txt
```

## 2. ريل غامض: سؤال واحد، وبعدين تعارض

**الطلب:** «اعمل ريل دعاء الجمعة»

**الكارت:** مونتاج · L2 · وضوح 58% · القرار ❓ سؤال واحد.
- الخامة ❓ ناقصة (أثر 3 × عدم يقين 3 = **9** ← سؤال)
- المقاس ✅ (كلمة «ريل» = 9:16)، والصوت ✅ (دعاء)
- المدة 🟡 30–60ث، والأسلوب 🟡 سينمائي هادي (خطر 2 ← افتراض)

**الرد الأول:**
```
فهمت إنك عايز: ريل 9:16 لدعاء يوم الجمعة.
هعمل:
- أجهّز الدعاء (صوت + كابشن متزامن)
- لقطات هادية (سما، مسجد، نور) متزامنة مع الصوت
- معاينة 5 ثواني قبل الرندر الكامل
الناتج: reel.mp4 على سطح المكتب · ⏱ ~20–40 د
افتراضات: 30–45 ثانية، أسلوب سينمائي هادي، صوت ‎-14 LUFS.

❓ سؤال واحد قبل ما أبدأ: الخامة منين؟
ليه بسأل: ده اللي هيحدد شكل الريل كله.
1) ⭐ أدوّر أنا على خامات مجانية عالية الجودة وأسجّل مصادرها
2) من مجلد عندك (قولّي المسار)
3) خليط: اللي عندك + أكمّل الناقص
أو قول «نفّذ» وأمشي بـ ⭐.
⏳ وأنا مستني: بدوّر على تلاوة/دعاء بصوت واضح من غير حقوق.
```

**إجابة المستخدم:** «من عندي في D:/friday، بس عايزه 16:9 لليوتيوب»

**بعد الإجابة** (حدّث، دوّر على تعارض، عدّل، كمّل):
- قست المجلد: 9 فيديوهات، **كلها طولي 1080×1920**. المطلوب دلوقتي 16:9. ده تعارض.
- الرد:
```
اتحدّث: الخامة من D:/friday (9 فيديوهات)، والمقاس بقى 16:9 1920×1080.
⚠️ الخامة كلها طولي. الحل: ⭐ أحط كل لقطة في النص وخلفيتها نفس اللقطة متكبّرة ومبلورة (من غير ما تتقص)، أو أقص وأكبّر (هيقطع جزء من الصورة). همشي بـ ⭐ لو ماقولتش غير كده.
الخطة اتعدّلت: خطوة «تحويل المقاس» اتضافت بعد القياس.
```
- الكارت بيتعاد بـ `--known inputs=D:/friday aspect=16:9`، ومفيش سؤال تاني عن المقاس أو الخامة.

## 3. قرار: توصية مبدئية + سؤالين

**الطلب:** «أختار أنهي لابتوب للمونتاج؟»

**الكارت:** قرار (ومعاه مونتاج كنوع تاني) · L2 · وضوح 33% · ❓ سؤالين:
- أهم معيار (خطر 9)، والميزانية (أثر 2 × 3 = 6). الاتنين فوق الحد.
- الاختيارات 🟡 «أولّد أنا 3 بدائل».

**الرد الأول** (التوصية المبدئية **قبل** الأسئلة، عشان السؤال مايبقاش حيطة):
```
فهمت إنك عايز: ترشيح لابتوب مناسب لشغل المونتاج.
مبدئيًا: للمونتاج المهم كارت شاشة NVIDIA (RTX) + رامات 32GB + شاشة ألوانها مظبوطة، والمعالج بعدهم.

❓ سؤالين بس، والباقي مفترضه:
1. أهم حاجة؟ ← ⭐ أحسن قيمة مقابل السعر / أعلى أداء مهما كان السعر / الأخف في الشيل
2. الميزانية؟ ← ⭐ قولّي رقم تقريبي، ولو مفيش أطلّعلك 3 مستويات سعر
ممكن ترد «1⭐ 2: 60 ألف»، أو «نفّذ».
⏳ وأنا مستني: بجمع أسعار حديثة من السوق المصري.
```

**بعد الإجابة:** جدول مقارنة بالأسعار والمصادر والتاريخ، ومصفوفة موزونة محسوبة بالكود، وتوصية واحدة ⭐، وبديلين، وإيه اللي يقلب التوصية («لو هتشتغل 3D كتير، الأعلى في كارت الشاشة يكسب»).

## 4. كيبورد إنجليزي: فك وسؤال واحد

**الطلب:** `uhd. lihvm jt;dv`

**الكارت:** الفك ← «عايز مهارة تفكير» · مهارة جديدة · L2 · ❓ سؤال واحد عن القدرة.

**الرد الأول:**
```
فهمت إنك عايز: مهارة تفكير (فكّيت الكلام من الكيبورد الإنجليزي: «uhd. lihvm jt;dv» = «عايز مهارة تفكير»).

❓ سؤال واحد: المهارة تعمل إيه بالظبط؟
ليه بسأل: «تفكير» ممكن تبقى تخطيط للطلبات، أو حل مسائل، أو عصف أفكار، وكل واحدة مهارة مختلفة.
1) ⭐ تفكر وتخطط لكل طلب: تسأل لو مش واضح، تقترح، وتعمل ورك فلو
2) تحل مسائل وقرارات صعبة بعمق
3) تولّد أفكار إبداعية
أو قول «نفّذ» وأمشي بـ ⭐.
⏳ وأنا مستني: بقرا المهارات المتثبتة عشان مانكررش حاجة موجودة.
```
ممنوع هنا: «مش فاهم، ممكن تعيد الكتابة؟».

## 5. «نفّذ انت اللي تشوفه»: صفر أسئلة

**الطلب:** «نفّذ انت اللي تشوفه: اعمل بوستر لمعرض الكتاب»

**الكارت:** تصميم · L2 · القرار ▶️ go_all. فيه بنود ناقصة، بس الوضع ده بيلغي الأسئلة.

**الرد الأول:**
```
فهمت إنك عايز: بوستر لمعرض الكتاب، والقرارات عليا.
افتراضات (قولّي لو حاجة غلط):
- النص: «معرض القاهرة الدولي للكتاب» + سطر «اقرأ… لترى أبعد» + مكان فاضي للتاريخ
- المقاس: 1080×1350 بوست + 1080×1920 ستوري
- 3 اتجاهات: ⭐ كتاب مفتوح بيطلع منه نور (سينمائي دافي) / حروف عربي ضخمة تايبوجرافي / مدينة من الكتب
- التنفيذ ببلاش (HTML/SVG + magick) عشان الحروف العربي تبقى سليمة
الناتج: PNG بالمقاسين على سطح المكتب · ⏱ ~25–40 د
```

**التسليم:**
```
C:\Users\cinde\OneDrive\Desktop\بوستر_معرض_الكتاب\poster_post.png
- اخترت ⭐ «الكتاب والنور» لأنه أوضح فكرة وأقوى على شاشة الموبايل
- 1080×1350 و1080×1920 (الأبعاد اتقاست) · الحروف العربي اتشافت بالعين (view_image)
- 🟡 التاريخ مكانه فاضي: ابعتهولي وأحطه
```
