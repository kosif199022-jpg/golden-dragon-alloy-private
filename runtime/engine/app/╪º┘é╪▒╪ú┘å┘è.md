# التنين الأسود: إعادة بناء kosif-tool من الصفر

ده المستودع النضيف اللي اتبنى من الأول بدل kosif-tool. المستودعات الأصلية مااتلمستش.

## الاستخدام
افتح الترمنال في المجلد ده واكتب:
```
python -m dragon find "اللي عايزه بكلامك"     # يدوّر في 22,319 مهارة وأداة وقدرة
python -m dragon engines                      # يعرض المحركات الـ 11
python -m dragon run <محرك> <أمر> ...          # يشغّل أي محرك
python -m dragon film spec.json               # فيلم سينمائي من فيديوهات وأغنية (زي أفلام ميار)
python -m dragon verify out.mp4               # يقيس أي فيديو: المدة والجودة وعلو الصوت
```
الجديد في v1.2 (بوابة التسليم والأغاني):
```
python -m dragon verify film.mp4 --duration 45            # يرفض: فريمات سودا جوه الفيلم، MP3 جوه MP4، عدد فريمات مش round(45×fps)
python -m dragon mux video.mp4 song.mp3 film.mp4 --duration 45   # دمج بطول مضبوط بالفريم (من غير -shortest)، والصوت AAC
python -m dragon patch-black in.mp4 out.mp4               # يغطي الفريمات السودا جوه الفيلم بآخر فريم سليم، ويفحص تاني
python -m dragon align reel.mp4 song.m4a                  # أنهي حتت من الأغنية في الريل، ونقط قص المونتير
python -m dragon lyrics-sheet lyric.mp4 sheet.jpg --every 4   # لقطات شريط الكلمات في صفحة: نقرا الكلام المتغنّي بالعين
```
والأدوات من جذر المهارة: `python3 scripts/dragon.py tool tiktok-post <link> --out DIR` (صور وصوت بوست صور تيك توك) و`python3 scripts/dragon.py tool styles SPEC.json --out DIR --render` (أساليب الأفلام الستة).
أو قول لـ Claude «التنين الأسود» في أي طلب، ومهارة `black-dragon` المتثبتة هتشتغل.

## المحركات
| المحرك | بيعمل إيه |
|---|---|
| dragon_montage | مونتاج كامل من فيديوهاتك وطلبك: تحليل، ثم خطة، ثم مونتاج، ثم مراجعة |
| talking_head | ريل من فيديو حد بيتكلم: يقص السكتات، ويظبط الصوت، ويضيف كلام متحرك |
| cinema | أفلام تكريم واحتفال سينمائية، 9:16 بأغنية |
| web_film | أفلام موشن معمولة كصفحات ويب |
| editorial | لوك أرشيفي سينمائي: حبيبات وتوهّج ونص متحرك |
| shadow_theatre | أفلام مسرح الظل |
| voice_studio | صوت بتوقيت الكلمات، وتفريغ لترجمة SRT/VTT |
| reel_hooks | تقييم أول جملة في الريل، وتوزيع السكريبت على الثواني |
| kling_director | بروmpts كلينج وستوريبورد (من غير ما يصرف رصيد) |
| matrices | اختراع أساليب بصرية جديدة واختبارها |
| cards | 2,901 طريقة مونتاج وصوت، كل واحدة باختبار ليها إجابة معروفة |

## الإثبات
- كل محرك اتقارن بالقديم على نفس المدخلات: VMAF من 95 لـ 99.95، أو تطابق بكسل ببكسل، أو تطابق بالبايت.
- `python -m pytest -q tests`: ‏150 ناجح و1 متخطّي، وده اختبار طويل اختياري.
- v1.2 على سحابة claude (2026-11-08): ‏131 ناجح و123 متخطّي في 131 ثانية؛ المتخطّي محتاج ملفات أو برامج جهاز المالك. اختبارات v1.2 في `tests/test_v12_*.py` بتعمل الميديا بتاعتها بنفسها بـ ffmpeg.
