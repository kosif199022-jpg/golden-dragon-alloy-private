# V10 — إخراج Kling بالنص: بناء قصة واستمرارية

المصدر: مهارة `omar-hasan-kling-cinematic-director.skill` المرفقة. هنا طبّقنا أفكارها في **مُنشئ مخطط نصّي** لا يتصل بمنصة Kling.

**قصة قصيرة:** هدف البطل → تهديد حقيقي → محاولة سببية → انقلاب التوقع → تغيّر حكم المشاهد على البطل. يجب أن يبقى المعنى مفهومًا بدون صوت.

**الاستمرارية:** حدد ID ثابتًا للشخص والمكان والقطعة، واتجاه الحركة داخل الكادر، والعناصر التي يجب أن تنتقل بين بلوكين. الاستمرارية تحتاج مراجعة بشرية، ولا تضمنها النصوص وحدها.

**الإنتاج:** يقسّم `v10 kling-pack` الفيلم إلى بلوكات مدة كل منها ≤30 ثانية (≤20 للـFlash حسب مستند أكتوبر 2026)، ويوازن آخر بلوك ليبقى ≥3 ثوانٍ، ويولد لكل بلوك prompt نصيًا وستوري بورد 3×3 وصفيًا. لا يقوم بتحميل صور أو توليد الفيديو. مراجعة حدود وخيارات وأثمان Kling المعاصرة تتم خارج هذه الأداة قبل استخدام الخدمة.

**القيود:** استخدام مرجع ملامح شخص يحتاج تفويضًا، الصور المرجعية لا تُعطي حق استخدام حقوق طرف ثالث. الصوت العربي يمكن إضافته داخل المونتاج المرخّص بدل افتراض أن مزامنة شفة عربية مدعومة. وحدات `engines.kling_director.lint` السابقة محفوظة لفحص نص المطالبة.
