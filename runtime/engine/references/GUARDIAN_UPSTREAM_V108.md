المصدر: 396 رسالة من المالك في كل المحادثات من 2026-10-29 لـ 2026-11-10. اتقرت عشان نعرف إيه اللي بيتكرر ويضايق،
وكل مشكلة بقت أمر بيتقاس، وعليه اختبار على ملفات حقيقية (`app/tests/test_v108_care.py`).

## 1) «الملف لا يعمل» / «اغنية شتا الرياض لا تعمل» ← `play-check`
```
python scripts/dragon.py play-check out/film.mp4          # يفحص
python scripts/dragon.py play-check out/film.mp4 --fix    # يعمل out/film_phone.mp4 جديد (الأصل مايتلمسش)
```
بيرفض:
- MP3 أو Opus أو FLAC جوه MP4، لأنه بيطلع ساكت على الآيفون، ولازم AAC.
- كوديك غير H.264. ولو HEVC من غير وسم `hvc1` الآيفون مش هيشغّله.
- `pix_fmt` غير yuv420p، وبروفايل 4:4:4 أو High 10.
- أبعاد فردية.
- ملف من غير `moov`: الرندر اتقطع، وده مش بيتصلّح غير برندر جديد.
- ملف فيه أخطاء لما بيتفك لآخره: تالف أو ناقص.

وبيحذّر من:
- ملف مش faststart: على واتساب والنت مش هيبدأ غير بعد ما يتحمّل كله.
- فيديو من غير صوت.
- تردد صوت غريب.
- أبعاد أكبر من 4K.

التصليح بينسخ اللي سليم زي ما هو، ويعيد ترميز اللي بايظ بس: AAC بـ 320k و48 kHz، أو H.264 High بـ CRF 17 وyuv420p وBT.709، مع `+faststart`.
وبعد التصليح الفحص بيتعاد على النسخة الجديدة. exit = 1 لو فيه ملف لسه مش هيشتغل.

## 2) «خلصت ولا لسه؟» / «هل انتهيت» ← `status`
المشغّل بيسجّل كل أمر شغل في `~/.black-dragon/jobs.jsonl`، وتقدر تغيّر مكانه بـ `DRAGON_STATE`. الأوامر السريعة زي find وwhere وdoctor مش بتتسجّل.
- `status`: الشغّال دلوقتي ومدته، وآخر الشغل اللي خلص ✅ أو فشل ❌ أو وقف من غير ما يخلص ⛔ (لو العملية ماتت).
- `status --all` للسجل كله، و`--json` للبرامج.

## 3) «فين الملف؟» / «اسم الملف ايه» ← `last`
- بعد أي أمر شغل، المشغّل بيطبع الملفات اللي طلعت بمساراتها الكاملة.
- `last` بيرجّعها في أي وقت (`last 20`، `--json`).
- القاعدة: آخر سطر في رد Claude يبقى المسار الكامل.

## 4) الرندر اتقفل «because the system is running low on memory» ← `resources`
- بيعرض الذاكرة الفاضية والهارد وعدد الأنوية وكارت الشاشة، وعدد الشغّالين المناسب (حوالي 1.5 GB لكل شغّال، و1 GB متساب لويندوز).
- قبل الأوامر التقيلة (film وrun وwords وmux وv10 …) المشغّل بيطبع تحذير بالعربي لو الذاكرة ضيقة، وبيحط `DRAGON_MAX_WORKERS`.
- اتقاس على جهاز المالك يوم 2026-11-10: الفاضي كان من 1.5 لـ 2.9 GB من 15.7. عشان كده المستوى كان «ضيق» وعدد الشغّالين 1.

## 5) «Transcribe Arabic audio with Whisper failed» ← التفريغ مايقعش
- لو موديل Whisper المطلوب مش متحمّل، `words` بيستخدم أول موديل متحمّل بالترتيب ده: large-v3-turbo، وsmall، وlarge-v3، وmedium، وbase، وtiny. وبيكتب سطر بيقول استخدم أنهي موديل.
- ومفيش تحميل موديل جديد غير بـ `--download` بعد موافقة.
- واتجرّب على الجهاز: طلب `medium` (مش متحمّل) واشتغل بـ `large-v3-turbo`.
- `words` بقى بيشتغل على محرك المهارة لو ريبو سطح المكتب أقدم.

## 6) رسايل زي `;LG` و`P'DJ TDK LIHVM HGJKDK` ← `tool layout`
دي عربي اتكتب والكيبورد إنجليزي، وأحيانًا Caps Lock كان شغّال.
```
python scripts/dragon.py tool layout "P'DJ TDK LIHVM HGJKDK"   # حطيت فين مهارة التنين
python scripts/dragon.py tool layout --detect ";LG"            # {"looks_wrong_layout": true, "arabic": "كمل"}
python scripts/dragon.py tool layout --to en "هىسفشمم"         # install
```
