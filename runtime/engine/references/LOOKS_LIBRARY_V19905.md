# مكتبة النماذج — الراجل والبنت واللبس والستايلات وطرق الشغل (v1990.5.0، اتوسعت في v1990.6.0)

كل نموذج استقرينا عليه ليه **رقم** و**صورة** و**prompt جاهز** و**لينك فيلم اتعمل بيه**. لما صاحب التنين يقول «اعمله زي بتاع القهوة» أو «بالشكل بتاع إسكندرية»، ابعتله ورقة الصور يختار منها بالرقم.

```bash
python scripts/dragon.py tool looks list                    # كل النماذج بأرقامها
python scripts/dragon.py tool looks list --kind wardrobe    # character / wardrobe / singer / expression / scene / style / layout / model
python scripts/dragon.py tool looks show W05                # الكارت: الاستخدام، الـ prompt، اللينك، مسار الصورة
python scripts/dragon.py tool looks sheet looks.jpg         # ورقة صور واحدة والأرقام عليها: ابعتها له يختار
python scripts/dragon.py tool looks prompt C01 W07 E03 --scene "she holds a hot drink by the sea"
python scripts/dragon.py tool looks find "زي فيلم الخريطة بتاع ميار"   # v1990.6: بحث بالعربي
python scripts/dragon.py tool looks remind "بالراجل والست" --out DIR  # v1990.6: صورة لكل نموذج قريب ← ابعتها له الأول
#  ↑ بيطبع params جاهزة لـ generate_image_batch (gpt_image_2_6، 9:16، والمرجعين) + شرط الحشمة
```

## الأنواع

| wardrobe | W01–W11 | اللبس والمكان مع بعض: الكلاسيك الأحمر/الرمادي، القاهرة الستينات، صيف المتوسط الأصفر، تراس الغروب، القهوة المصرية، بلكونة النيل، شتا إسكندرية، الحارة المزيّنة، ساحة الخيل، الحوش الحجري بالعود، الشارع بالفوانيس |
| singer | G01–G03 | البنت كمغنية لوحدها: جاكيت جلد بني (حفلة ميدان)، جاكيت جلد أسود (حفلة بالليل)، ساتان فضي (فرح) |
| expression | E01–E07 | تعبيرات الوش اللي اتنقلت من فيديو «يا راميني»: مكسوفة وإيدها على بُقها، باصص لتحت، دقنها على إيدها، بتضحك، بيوشوشها، سرحان وإيده على بُقه، راسهم جنب بعض |
| scene | SC01–SC07 | مشاهد من أغاني 9 نوفمبر: لوحدها في المطر، ماشيين بالليل، بتحلم بيه، حزينة وهو على الباب، حنطور على البحر، وداع في المحطة، وردة سحرية |

| layout | LY01–LY02 | مكان الكلام: فوق، أو تحت الوشوش |
| model | M01–M05 | موديلات Higgsfield وأسعارها اللي اتقاست |
| method | PM01–PM15 | (v1990.6) طرق الشغل من كل محادثات المشروع: أفلام ميار السبعة، عالم واحد بالخريطة، مسرح الظل، الزجاج والضوء، المناظرة، ريل القهوة، إعادة التأطير، الكرتون بالكود، الستوري بورد. الصور من الأفلام اللي اتسلمت، و`example` مسار الفيلم في فولدر المشروع المشترك (`/mnt/project-files/…`، مش موجود في محادثة claude.ai العادية) |

**القاعدة (v1990.6):** قبل ما تستخدم أي نموذج طلبه بالاسم، `remind` وابعتله الصورة والرقم واستنى «أيوه». الخلاصة الكاملة: `PROJECT_HARVEST_V19906.md`.

## القواعد اللي ماشية على كل النماذج
- فستان البنت: ياقة عالية وكُمّ طويل والصدر متغطي، دايمًا.
- الكلام ما يقعدش على وش. صفر مؤثرات فوق الصورة (`fx check`).
- ريل فيه شخص حقيقي: بنعمل الكرتون بلبس قريب، مانقلش الوش.
- الصور في `tools/looks/img/` مصغّرة (360×640). اللينك في كل كارت هو الفيلم الكامل.

## فيلم كامل من نموذج (الطريق اللي اتجرّب)
1. `tool looks prompt …` لكل لقطة → `generate_image_batch` (≤ 12).
2. `python tools/lyric_couple/imgs.py JOB/film/img a1=<hf stem> …` (تنزيل + تفتيح + عمق + ورقة).
3. اكتب `spec.json` (اللقطات والكلام بالتوقيت) → `python scripts/dragon.py tool lyric JOB spec.json`.
4. `dragon.py fx new JOB/effects.json` و`fx check JOB/effects.json --html JOB/film/index.html`.
5. stills بـ `tools/render_html.cjs --stills` (لو موجود) واتفرج عليهم.
6. `bash tools/lyric_couple/render.sh JOB OUT.mp4` في الخلفية، و`--from S` لو وقع قرب الآخر.
7. اقرا `JOB/verify.txt` (لازم OK) قبل الرفع، وبعد الرفع امسح المحلي.
