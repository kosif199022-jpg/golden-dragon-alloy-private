# فهرس ميار المرفق — بحث دون سحب وسائط

تم تحويل ملف الروابط الذي أرفقه المستخدم إلى `app/data/v10_media_links.json`، مع التمييز بين **الروابط المرقمة 1–115** وأي روابط إضافية في نهاية الملف. كل رابط يحمل `opened: false` و`rights: unknown`، حتى لو كان العنوان يصف حدثًا عامًا.

```
python scripts/dragon.py v10 links --keyword "البرلس" --limit 12
python scripts/dragon.py v10 links --keyword "تتويج" --limit 5
```

لا تتطلب هذه الأوامر الإنترنت ولا تنزّل أي فيديو. لا تُستخدم مواد الأطفال لصنع وجه أو صوت اصطناعي يوهم بالحدث الحقيقي. استخدام الصور الأصلية في مشروع منشور يحتاج مراعاة الأذونات والحقوق.
