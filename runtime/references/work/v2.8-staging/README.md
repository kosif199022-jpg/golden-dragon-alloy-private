# مواد شغل نسخة 2.8 (من `v2.8.rar`)

دي ملفات مجلد الشغل `~/rd-staging/v2.8` اللي ماكانتش في `red-dragon-v2.8.1.zip`. محدش بيشغّلها ولا بيقراها:
- سكربتات مساعدة (`_*.py`).
- تفريغات وكلاء التقييم (`mind/route_eval/_agent2`، `_agent4`).
- مقترحات الكلمات والإملاء.
- كل الرسايل (`turns_all.json`).
- نسخ احتياطية من 2.7 (`_dictation_v27_backup.json`، `_playbooks_v27.json`).

اتحفظت هنا عشان شغل 2.8 يفضل قابل للمراجعة والإعادة. كل ملف موجود في 2.8.1 وفي الـ rar بنفس الاسم طلع متطابق بالبايت.
