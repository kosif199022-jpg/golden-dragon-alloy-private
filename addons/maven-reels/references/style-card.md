# The style card

After `analyze.py`, fill this in from `analysis.md` and the sheets. It is the contract for the new reel: everything
you build must match it. Keep each answer to one line. Save it as `style-card.md` next to the reel.

```
FORMAT     9:16 · 40 s · one continuous camera / hard cuts every N s
STRUCTURE  the beats in order, e.g. hook (build the place) -> problem grows x3 -> failed fix -> the product -> how it works x3 -> payoff -> logo
HOOK       what is on screen in the first 1.5 s and what moves
VOICE      first person / narrator / none · dialect · N words a second · first word at N s
CAPTIONS   one word at a time / full line · position · font weight · colour · shadow · how it enters
WORLD      flat / soft 3D / photo / paper · main places · palette (3-5 hex from analysis) · light (day, night, dawn)
CHARACTERS none / toy people / mascot · size on screen · how they move
CAMERA     push-in / pans along / cuts · zoom range · punch on key words?
GRAPHICS   phone UI / icon dock / counters / stickers / end card ...
PACE       a new visual event every N s (count them in the sheet) · busiest moment
SOUND      voice + music bed / voice only / music only · loudness · pops on every build step?
END        what the last 3 s show and the call to action
DON'T COPY the brand, logo, characters, slogan and script of the reference
```

## How to read a reference
- **Cuts vs moves.** `analysis.md` says when there are few hard cuts: then the reel is one camera that pushes and
  pans, and every change is something popping in. Copy that, not a slideshow.
- **Events per second.** Count, in `sheet.jpg`, how many seconds pass between new things (a person, a sign, a
  number). Founder-story ads add something almost every second.
- **Hook.** `hook.jpg` is 4 frames a second. Note whether the first frame is already busy or builds up.
- **Words a second.** From `analysis.md`. Arabic ads run 2.5-3.5. Faster than the reference feels rushed in a
  copy; slower feels dull.
- **Palette.** Take the 3-5 biggest colours from `analysis.md` and check them against the sheet. Use them for sky,
  ground, brand and accent.
- **Loudness.** Most reels are -14 LUFS or louder. The renderer delivers -14.
