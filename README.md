# Dua voices by day (private study library)

2,126 dua recordings (audio only, m4a) from the TikTok accounts @dxhmen (757 reels) and @oaun.11
(1,369 reels), sorted by the day or occasion named in each caption:

`<account>/<label>/<date>_<tiktok id>.m4a`. Labels: friday_night, friday, saturday … thursday,
`<day>_morning`, ramadan, eid, arafah, shaban, rajab, mawlid, fajr, quran, new_month, other.
`dua_audio_catalog.csv` lists every file with its TikTok link.

Made with Red Rose `agent/dua_audio/dua_audio.py` (list + label) and `fetch_audio.py` (sandbox).

These voices belong to their creators. Keep this private: use it to study tone, pace and wording.
For a published reel use the owner's own voice, or the original sound inside the TikTok app.

Fetch this branch alone:
`git clone --single-branch -b media/dua-audio https://github.com/kosif199022-jpg/golden-dragon-alloy-private dua-audio`
