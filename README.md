# Pinterest clips in the @dxhmen look (private reference library)

152 vertical clips found on Pinterest by searching the look of the TikTok account @dxhmen
(daily dua reels): sunset sea, gold incense burners, Quran with roses and candles, the Prophet's
Mosque and the Kaaba, camels in the desert, flower fields, swings by the sea, clouds, dawn,
rain on mosques, Ramadan lanterns, Arabic coffee.

- `clips/<theme>/<pin id>.mp4`: original files as Pinterest serves them (no re-encode).
- `catalog.csv`: file, theme, size, length and the Pinterest link of every clip.
- `pins_search_results.json`: the raw search results (16 themes).

These clips belong to their makers. Use them for private drafts and style study; for a published
reel prefer your own footage or footage with a clear licence.

This branch holds media only. To fetch it alone:
`git clone --single-branch -b media/dxhmen-pins https://github.com/kosif199022-jpg/golden-dragon-alloy-private dxhmen-pins`
