# التنين الذهبي جوه Claude Code (من غير التطبيق)

المجلد ده بيخلّي أي محادثة Claude Code على الجهاز تبقى «التنين الذهبي» بكل قدراته، من غير ما تطبيق التنين يكون مفتوح.

## التثبيت

```bash
python -X utf8 install.py
```

بعدها افتح محادثة Claude Code جديدة. ولإلغاء التثبيت: `python -X utf8 install.py --uninstall`، ولمعرفة إيه المتثبت: `--status`.

## اللي بيتثبت

| الحاجة | الملف | بتعمل إيه |
|---|---|---|
| تعليمات التنين | `gen_prompt.py` ← `~/.claude/golden-dragon/GOLDEN.md`، وسطر استيراد واحد في `~/.claude/CLAUDE.md` | نفس تعليمات التطبيق بالحرف، متولّدة من `../app/app.py`، فمفيش نسختين |
| عقل التنين قبل كل رسالة | `brief_hook.py` (hook من نوع UserPromptSubmit) | بيشغّل `rd.py brief`: بيفك الكيبورد والصوت، ويقترح الطريق، ويجيب الدروس |
| خادم `golden-dragon-app` | `golden_mcp.py` | `computer`، `system`، `browser`، `fusion`، `gold`، `skills`، `voice`، `compare`، `control` |
| خادم `golden-dragon` | `../app/mcp_dragon.py` | كتالوج التنين، والمحركات، والهندسة العكسية (retool، rea، omni)، والربط بالتطبيق لو مفتوح |
| الوكلاء | `~/.claude/agents/golden-reviewer.md` و`golden-helper.md` | مراجع التفكير 🧐، والمساعد اللي بيشتغل بالتوازي |

## الأمان

- **الأفعال الخطيرة:** قفل برنامج، والخدمات، وإزالة برنامج، والإطفاء، وإعادة التشغيل، وتسجيل الخروج، وكمان تثبيت المهارات وشيلها وفك برامج الاستوديو. كل دي بتطلّع نافذة «نعم/لا» من ويندوز، والإنسان اللي قدام الجهاز بس هو اللي يقدر يوافق. لو مفيش رد في 3 دقايق، بتتحسب «لا».
- **فرملة الطوارئ:** حط الماوس في الركن الشمال اللي فوق، والتحكم كله يقف لحد `control action=resume`.
- **شيل المهارة** بينقلها لـ `~/.claude/skills_backup`، ومابيمسحهاش.
- **قبل أي تعديل** بيتعمل نسخة احتياطية في `~/.claude/golden-dragon/backups/`، والوكيل اللي إنت عامله بنفسك بنفس الاسم مابيتلمسش.
- **مفيش رفع ولا نشر ولا صرف رصيد** غير بموافقة صريحة في الشات.

## الفرق عن التطبيق

مفيش نافذة ولا لوحة معاينة حية، ومفيش «فوق كل النوافذ»، والمخ Claude بس (ChatGPT وGemini بيتسألوا عن طريق `compare`). إضافة كروم «التنين الذهبي» مش بتشتغل من هنا لو التطبيق مفتوح، لأنه ماسك نفس البورت؛ ساعتها استخدم Claude in Chrome. الجرد الكامل في `INVENTORY.md`.
