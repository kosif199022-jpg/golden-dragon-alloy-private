# V63 — dependency planning, robust choice and risk
Original deterministic functions inspired by selected excerpts in the owner-provided skills.zip (receipt: V63_MIND_SOURCE_RECEIPT.json). Does not train a model, run tasks, or authorize actions.
- mind schedule INPUT.json: tasks [{id,duration (positive integer in a consistent unit),depends_on:[ids],deliverable,acceptance}]. Validates the DAG, rejects unknown dependencies, cycles and duplicate identifiers. Returns earliest/latest start, slack, critical path, dependency layers, and a precedence-only duration lower bound. Does not account for resource limits or verify durations.
- mind decision INPUT.json: criteria [{id,weight}], required [hard-gate IDs], alternatives [{id,gates:{gate:true/false/null},scores:{criterion:0..100, [lower,upper] or null}}]. Excludes failed or unknown hard gates. Null scores range from 0 to 100. A robust winner must strictly dominate all other eligible intervals; uncertainty is retained, not replaced by a guessed value. Weights/scores and gate claims are user supplied.
- mind risks INPUT.json: risks [{id,likelihood:1..5,impact:1..5,failure,trigger,owner,status,mitigation?,evidence?}]. Unresolved critical-impact or high-product risks block review even if unlikely. Mitigated/accepted claims require evidence text, but the text is not authenticated. The operation cannot grant execution authority.
Use alongside V62 experiments/diagnose/acceptance, the V51 evidence gate and the existing domain-specific verification. For dua always enforce the mandatory approved source and font instructions. The content-analysis index is lexical triage only; a hit is not semantic understanding, an executable capability or a verified license. No raw skill documents copied into Git.
