# V65 code montage engine
Native Python/FFmpeg renderer for **general** montage, no external service. Reviewed eight source skill excerpts (see V65_MONTAGE_SOURCE_RECEIPT.json). Original code, not the Remotion/HyperFrames renderer itself. Do not use for dua/azkar or source-style reconstruction: follow the mandatory owner dua and typography rules and existing V57/V58 paths. This renderer is not integrated into the old renderers.
## Job schema
Run python rose.py montage-code plan JOB.json, then python rose.py montage-code render JOB.json --output NEW.mp4 --approve-write.
Required kind="general", rights_confirmed=true (declaration, not independent proof), workspace absolute local directory, width/height even, fps 24/25/30/50/60, shots [{file relative path,frames,source_start_frame?,overlap_frames?,transition?,zoom_end?}]. Source video is resampled to target fps before trim, no claim of original VFR frame indexing. Still PNG/JPEG optional centered eased zoom (1–1.5). Transition cut (no overlap), fade or smooth-fade with overlap. Total frame count = sum lengths minus overlaps; reject triple overlaps. Audio is separate approved local file, or explicit allow_silent=true. Audio shorter than timeline blocks. normalize_audio=true runs one loudnorm filter and measures final AAC integrated LUFS/true peak (-16 LUFS +/-1.5, true peak <= -1.0 dBTP). Defaults may not suit all content. No dialogue alignment, multi-track mixing, visual font matching or HDR color-management.
## Checkpoint and output
The cache is .rose-montage-v65 under the job workspace, keyed by complete plan/source hashes, FFmpeg version and engine source digest. Same unchanged plan reuses individually verified chunks; any edited plan creates a new cache. Cache receipts, full decode and digests guard reuse. Corrupt chunks rebuilt; lock released by OS on crash; same-filesystem atomic hard link publishes new output without overwriting. Filesystem must support hard links. Failed runs may leave unlinked partial staging files; inspect before cleanup. Source digests rechecked before delivery. Exact PTS and frame count verified, H264/yuv420p, AAC/duration, first-frame nonblack heuristic. No all-frame black, perceptual, subtitle or style certification. Render still must be inspected by a human. Never publish private assets/cache/commands. Test output and receipts stay local.

Assembly decodes each chunk independently via the concat filter, not demuxer stream concatenation. This prevents dropped/reordered frames at independently encoded MP4 boundaries. The final exact-PTS gate remains mandatory.
