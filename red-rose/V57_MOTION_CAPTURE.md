# V57 — local motion capture and reuse
Read AGENT_NOTES.md first. Use python rose.py motion-capture analyze VIDEO --regions REGIONS.json --fps 60 --output TRACK.json --approve-write (default 12 FPS, maximum 60 and 300 seconds; only local file). Regions are normalized rectangles with id, box [x0,y0,x1,y1], kind white/yellow. Exclude measured text zones from the camera estimator. Output includes frame numbers, nominal timestamps, local affine similarity matrices, center displacement, zoom, rotation, RANSAC quality, observed ink boxes/color/count, luma, sharpness and candidate discontinuities/dips. Replay a stored measurement: python rose.py motion-capture replay TRACK.json --time 3.5. Never fill lost measurements with invented motion; an anchor/cut or low texture can break a trajectory. This is a reusable measured record, not full semantic animation recovery, actual text opacity, verified font, perfect transition classification or renderer integration. Matrices are in proxy pixel coordinates; scale by the target/proxy dimensions before applying. OpenCV/numpy required for analysis; no network or paid service. The existing motion_v27 and motion_tracks remain unchanged.
Source review: GoldenDragon fusion index identifies motion-reference-probe, motion_lib and motion runtime; existing Rose motion_tracks/motion_v27 contain interpolation and rendering. Reviewed MIT-licensed AdamSpannbauer/python_video_stab checkout e005882 for optical-flow/trajectory concepts. V57 independently implements forward/backward matching, RANSAC, masked overlays and explicit loss handling; no copied third-party source or binary. 33 focused tests passed on Windows including known translation, zoom, rotation and actual encoded synthetic tracking. Masked-text test originally failed, then passed after suppression of overlay pixels in both pyramids. Real reference run is a separate measurement, not style certification.
